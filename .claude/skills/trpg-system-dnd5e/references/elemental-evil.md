# 元素邪妄玩家擴充 Elemental Evil Player's Companion

> 依使用者收藏的中譯本整理摘要。原為冒險《滅世親王 Princes of the Apocalypse》的配套玩家選項，經 DM 同意可用於其他戰役。種族數值見 `races.md`。

## 背景

元素邪妄是一股威脅被遺忘國度的宇宙級邪惡：四大元素魔王（例如土之親王歐雷莫奇 Ogremoch）的邪教在德沙林谷地一帶擴張。書中提到的人物與組織：
- 豎琴手法師**澤爾蘭·怒號**與氣之預言者**艾瑞斯·卡利諾斯**、**怨嘯教**（氣元素邪教）
- 阿蘭寇拉鷹人與風之公爵、**七節權杖**的傳說，以及與侍奉土之親王的石像鬼之間的宿怨

## 種族背景建議

| 種族 | 適合的背景 |
|------|-----------|
| 阿蘭寇拉鷹人 | 化外之民、隱士、智者 |
| 氣元素裔 | 騙子、藝人、貴族 |
| 土元素裔 | 隱士、化外之民、士兵 |
| 火元素裔 | 罪犯、平民英雄、貴族 |
| 水元素裔 | 隱士、水手 |

**被遺忘國度中的分布：** 鷹人聚居在星之山脈、風暴之角、裂隙山脈、楚爾特的迷霧絕壁；地底侏儒住在幽暗地域；氣與火元素裔多是昔日統治卡林珊的巨靈後裔，分布於費倫西部；土元素裔多源自北地；水元素裔多來自墜星海沿岸；歌利亞住在高山上，重視公平競爭與自我超越。

# D&D 5e 規則速查

> 依 5e 基本規則（SRD 5.1）的內容整理摘要。使用者的玩家手冊中譯檔在第 3 章之後無法擷取文字，本頁用於補足戰鬥、冒險與施法的核心規則。

## 屬性與技能

| 屬性 | 技能 |
|------|------|
| 力量 STR | 運動 Athletics |
| 敏捷 DEX | 特技 Acrobatics、巧手 Sleight of Hand、隱匿 Stealth |
| 體質 CON | （無技能，用於生命值、專注、耐力） |
| 智力 INT | 奧秘 Arcana、歷史 History、調查 Investigation、自然 Nature、宗教 Religion |
| 感知 WIS | 馴獸 Animal Handling、洞悉 Insight、醫藥 Medicine、察覺 Perception、求生 Survival |
| 魅力 CHA | 欺瞞 Deception、威嚇 Intimidation、表演 Performance、遊說 Persuasion |

- **群體檢定**：隊伍一起做同一件事時，半數以上成功即整組成功。
- **協助**：幫助他人做檢定，使其獲得優勢。
- **對抗檢定**：雙方各擲，高者勝；平手維持現狀。

## 冒險

- **時間**：戰鬥以輪（6 秒）計，探索以分鐘或小時計，旅行以天計。
- **旅行速度**：快速（每小時 4 哩，被動察覺 −5）、正常（3 哩）、緩慢（2 哩，可以潛行）。
- **光照**：明亮、昏暗（輕度遮蔽，察覺檢定劣勢）、黑暗（重度遮蔽，等同目盲）。
- **墜落**：每 10 尺 1d6 鈍擊傷害，至多 20d6。
- **窒息**：可憋氣 1 ＋ 體質調整值分鐘（至少 30 秒）。
- **力竭**：6 個等級，累積懲罰（檢定劣勢 → 速度減半 → 攻擊與豁免劣勢 → 生命值上限減半 → 速度 0 → 死亡），長休並進食飲水可降一級。

## 戰鬥

**流程：** 判定突襲 → 決定位置 → 擲先攻 → 依序行動 → 下一輪。

**回合內容：**
- **移動**：速度以內，可在動作前後分段；困難地形每尺耗 2 尺；起身耗一半速度。
- **動作**（一個）：攻擊、施法、疾走（再多一倍速度）、撤離（本回合移動不引發借機攻擊）、閃避（對你的攻擊有劣勢、敏捷豁免有優勢）、協助、躲藏、準備（設定觸發條件用反應執行）、搜索、使用物件。
- **附贈動作**（至多一個）：只有特性或法術明言時才有。
- **反應**（每輪一次）：借機攻擊（敵人離開你的觸及範圍時）、準備動作、部分法術。
- **免費互動**：拔劍、開門等一個簡單物件互動。

**攻擊：**
- 近戰：力量調整值（靈巧武器可用敏捷）；遠程：敏捷調整值。
- 遠程攻擊在長射程或 5 尺內有敵人時有劣勢。
- 掩護：半身掩護 AC 與敏捷豁免 +2、四分之三掩護 +5、完全掩護無法被直接指定。
- 看不見的目標攻擊有劣勢；隱形的攻擊者有優勢。
- **擒抱**：以攻擊動作其中一次，進行運動對抗目標的運動或特技，成功則目標被擒抱（速度 0）。
- **推撞**：同上對抗，成功則推開 5 尺或使其倒地。

**傷害與治療：**
- 傷害類型：強酸、鈍擊、冷凍、火焰、力場、閃電、黯蝕、毒素、心靈、光耀、穿刺、揮砍、雷鳴。
- 抗性減半、易傷加倍、免疫無效。
- **重擊**：所有傷害骰擲兩倍，修正值不加倍。
- **生命值 0**：若剩餘傷害 ≥ 最大生命值則即死；否則倒地昏迷，開始死亡豁免。倒地時受到傷害算一次死亡豁免失敗（重擊算兩次）。
- **穩定**：他人以動作做感知（醫藥）DC 10 成功即穩定，1d4 小時後回復 1 點生命值。
- **非致命擊倒**：近戰將目標打到 0 時可選擇讓其昏迷而非瀕死。

## 休息

- **短休**：至少 1 小時。可花任意數量的生命骰，每顆回復（生命骰＋體質調整值）。
- **長休**：至少 8 小時（最多 2 小時輕度活動），每 24 小時一次。生命值全滿，回復至多一半等級數的生命骰。

## 施法

- **法術位**：施放 1 環以上法術消耗對應或更高環的法術位；高環施放可能增強效果。戲法不耗法術位。
- **施法時間**：多為一個動作；附贈動作施法的回合，只能再施放一個戲法（施法時間一動作）。
- **專注**：同時只能維持一個專注法術；受到傷害時做體質豁免，DC 為 10 或傷害一半（取高），失敗即中斷；失能或死亡也會中斷。
- **儀式**：標有儀式的法術可多花 10 分鐘施放而不耗法術位（職業需具備儀式施法）。
- **成分**：言語（被消音時無法施放）、姿勢（需要一隻空手）、材料（可用法器或材料包代替，除非標明價值或會被消耗）。
- **區域形狀**：錐形、立方、圓柱、線形、球形。

## 狀態 Conditions

| 狀態 | 效果摘要 |
|------|----------|
| 目盲 | 看不見；對你的攻擊有優勢，你的攻擊有劣勢 |
| 魅惑 | 不能攻擊魅惑者；魅惑者對你的社交檢定有優勢 |
| 耳聾 | 聽不見 |
| 恐慌 | 能看見恐懼來源時，檢定與攻擊有劣勢，且不能主動靠近它 |
| 擒抱 | 速度為 0 |
| 失能 | 不能採取動作或反應 |
| 隱形 | 需要魔法或特殊感官才看得見；你的攻擊有優勢，對你的攻擊有劣勢 |
| 麻痺 | 失能、不能移動或說話；力量與敏捷豁免自動失敗；對你的攻擊有優勢，5 尺內命中即重擊 |
| 石化 | 變成石頭，失能，大部分傷害抗性 |
| 中毒 | 攻擊與屬性檢定有劣勢 |
| 倒地 | 只能爬行；你的攻擊有劣勢；5 尺內對你的攻擊有優勢，更遠的有劣勢 |
| 束縛 | 速度為 0；你的攻擊與敏捷豁免有劣勢，對你的攻擊有優勢 |
| 震懾 | 失能、不能移動、言語含糊；力量與敏捷豁免自動失敗；對你的攻擊有優勢 |
| 昏迷 | 失能、倒地、不知周遭；力量與敏捷豁免自動失敗；對你的攻擊有優勢，5 尺內命中即重擊 |
| 力竭 | 見「冒險」一節 |

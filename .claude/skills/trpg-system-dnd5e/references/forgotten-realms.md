# 被遺忘國度（Forgotten Realms）世界素材

> 依使用者收藏的《國度的歷史》（The Grand History of the Realms 中譯）整理摘要。該文字檔從雷霆時代讀到約 −620 DR（耐色瑞爾鼎盛期），之後的歷史未收錄。書中以 1375 DR「精靈復興之年」為「現今」；5e 官方冒險多設定在 1480 DR 前後，開局時由范恩與使用者確認時間點。

## 基本地理

- **托瑞爾 Toril**：世界本身。**費倫 Faerûn** 是主要大陸，冒險多發生在西北的**劍灣 Sword Coast**、**北地 The North**，以及地底的**幽暗地域 Underdark**。
- 重要地名：深水城 Waterdeep、博德之門 Baldur's Gate、永聚島 Evermeet（精靈的島嶼故鄉）、科米爾 Cormyr、卡林珊 Calimshan、至高森林 High Forest、落湮沙漠 Anauroch（前耐色瑞爾帝國所在）、楚爾特 Chult、墜星海 Sea of Fallen Stars、陰魂城 City of Shade。
- 東方有翔龍 Shou Lung、倭 Wa 等國；遙遠的扎哈拉 Zakhara 對費倫人而言近乎傳說。

## 曆法

**谷地曆 Dalereckoning（DR）** 是通用紀年，起於人類首次獲准在谷地定居的那一年。其他曆法與 DR 的換算：

| 曆法 | 換算 |
|------|------|
| 科米爾曆 CR | 始於奧博斯卡王朝建立科米爾（26 DR） |
| 北地曆 NR（深水城、銀月聯盟） | DR − 1032 |
| 耐色瑞爾曆 NY | DR + 3859 |
| 翔龍曆 | DR + 1250 |
| 倭曆 | DR + 418 |
| 穆爾霍蘭德曆 MC | DR + 2134 |
| 恩瑟曆 UC | DR + 735 |
| 阿瑞賽瑪利爾曆 AC（海精靈） | DR + 11004 |
| 現代曆 PR | DR − 1358 |

自 −700 DR 起，每一年都有「年號」（例如「豪雨之年」「熾熱目光之年」），源自預言家編纂的《年表 Roll of Years》。在對話或文件裡使用年號，能讓 NPC 的時間感更有國度味。

## 古代史各紀元

| 紀元 | 年代 | 大事 |
|------|------|------|
| **雷霆時代** The Days of Thunder | −35000 ～ −30000 DR | 冰河期結束。**創造者種族**統治世界：蜥蜴類的撒魯克巫虺 Sarrukh 建立奧寇斯、梅爾紹克、伊斯托賽菲弗等帝國；蛙類的巴契茲魔魚 Batrachi；鳥類的艾夸—哈斯塔 Aearee-Khaastas。它們最終衰落、沉眠或退往他界 |
| **黎明時代**（龍與巨人的時代） | −30000 ～ −24000 DR | 巨龍與巨人爭霸；龍隕之戰等大型衝突；獸人、豺狼人等種族崛起 |
| **第一次繁盛** The First Flowering | −24000 ～ −12000 DR | **精靈**抵達並建立大國（艾瑞凡達 Aryvandaar、麥葉理塔 Miyeritar、伊利斯瑞 Illefarn 等），月精靈在阿笛普、綠精靈在艾伊魯爾定居；精靈高等法師施行**大陸分離 The Sundering**（約 −17600 DR）創造永聚島；**矮人**在地底建立第一個大王國（約 −15000 DR） |
| **皇冠戰爭** The Crown Wars | −12000 ～ −9000 DR | 五次精靈內戰。艾瑞凡達征服麥葉理塔；**卓爾**因背叛被放逐至幽暗地域；精靈文明元氣大傷，人類部落開始在戰火空出的土地上定居 |
| **開創紀元** The Founding Time | −9000 ～ −3000 DR | 矮人帝國沙納塔 Shanatar 分裂並爆發地底戰爭（衍獸之戰、蜘蛛戰爭，對抗卓爾）；伊瑪斯卡 Imaskar 帝國在今日落湮沙漠建立；杜卡結社崛起；各地人類王國萌芽 |
| **耐色瑞爾興盛期** | 約 −3000 ～ −620 DR（文字檔止於此） | **耐色瑞爾 Netheril** 取得創造者種族的**耐色卷軸**，建立浮空城（蘇爾坦薩 Thultanthar，即日後的陰魂城，−1471 DR）；卡林珊的卡迦安王朝鞏固；−1064 DR 耐色瑞爾人首次接觸**奪心魔**；−696 DR 最偉大的大法師**卡爾薩斯 Karsus** 誕生（他日後的狂妄將導致帝國覆滅） |

## 冒險可用的元素

- **失落的創造者種族遺跡**：撒魯克巫虺沉眠的叢林深處、巴契茲魔魚的後裔棲息的黑暗沼澤——適合作為古代恐怖或禁忌知識的源頭。
- **耐色卷軸**：記載創造者種族力量的卷軸，數度失竊、散佚——經典的「麥高芬」。
- **精靈的皇冠戰爭遺產**：被詛咒的古戰場、卓爾對地表精靈的千年仇恨。
- **地底矮人王國的廢墟**：沙納塔的殘骸與卓爾、灰矮人、地底侏儒的勢力交錯，直接接上《逃離深淵》。
- **浮空城與奧術傲慢**：耐色瑞爾的故事是「力量終將反噬」的範本，可作為世界真相或核心真相的原型。

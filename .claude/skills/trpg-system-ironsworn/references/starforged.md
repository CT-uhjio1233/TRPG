## 1. 基調與靈感

以人類為中心的**邊疆科幻**：拾荒拼湊的未來、稀缺的資源、遺失的知識。人們在不宜居的星球與偏遠太空站掙扎求生。作者列出的靈感：《曼達洛人》、原版《星際大戰》三部曲、《螢火蟲》、《異形》、《沙丘》、新版《星際大爭霸》、《太空無垠》、《星際異攻隊》。基調可依真相自由調整。

## 2. 舞台：熔爐 The Forge

熔爐是繞行人類母星系的**球狀星團**（NSC 8412），位於銀河平面上方 1,700 光年，是黑暗虛空中的明亮孤島。星雲、行星際塵埃與奇異能量交織，恆星風暴與不可預測的重力流不斷。兩百年前，人類因母星系的大災變逃到這裡。

| 區域 | 概況 |
|------|------|
| **終點 Terminus** | 人類登陸之處。聚落常見，派系爭奪資源，太空商隊沿已知航道往來，但仍有未知與孤立的區域 |
| **外域 Outlands** | 近幾十年才開拓，聚落零散，航道多半未經測繪 |
| **遠疆 Expanse** | 少數勇敢的拓荒者抵達的遙遠區域，孤立的聚落與已開發區域失聯 |
| **虛空 Void** | 熔爐之外，只剩寥寥孤星與無垠的虛無，幾乎無法抵達 |

### 星際航行

- **幻影引擎 Eidolon drive（e-drive）：** 利用熔爐的湍流力量，讓船隻以超光速沿最佳路徑前進。
- **漂流帶 Drifts：** 熔爐中由重力流、恆星風與烈焰能量構成的航行網路，駕駛像衝浪一樣乘浪前進。
- **航道 Passage：** 在漂流帶上規劃好的航線。已開發區域的重要地點通常有航道相連，但導航資料是被掌權者把持的寶貴資源；其他人只能自己開路。
- **錨泊點 Anchorage：** e-drive 最多運轉數小時、需要數小時充能，所以長途航行是一段段超光速跳躍，每段在錨泊點（通常靠近恆星或行星）結束。
- **幻影鬼魂：** 有人說幻影航行會削弱現實的邊界，漂流帶中常有可怕的幻象；太空人迷信，常用護符與儀式驅趕。

### 科技

預設為**復古未來**——用二三十年前的眼光想像的未來，資源稀缺、大量知識在災變後失傳。槍是電漿還是實彈、飛船是流線型還是靠禱告撐著，由真相決定；也可以設定階級差距：先進科技只屬於權貴。

## 3. 與經典版的主要差異

| 項目 | Starforged 的做法 |
|------|------------------|
| 屬性 | 同樣是迅捷、心志、鋼鐵、暗影、機智，開局 1–3 |
| 狀態條 | 生命、精神、補給（補給同樣由同行者共用） |
| 衰弱 → **影響 Impacts** | 每個影響使動能上限 −1；1 個影響時重置值 +1，2 個以上為 0 |
| 經驗 → **傳承軌 Legacy Tracks** | 任務 Quests、羈絆 Bonds、發現 Discoveries 三條軌；招式給予「傳承獎勵」標記刻度，每填滿一格做 *Earn Experience* 得 2 經驗（軌道清空重來後改為 1） |
| 精進 | 新資產 3 經驗、升級 2 經驗 |
| 載具 | 指揮載具（STARSHIP，全隊共用）、支援載具、臨時載具，各有完整度 Integrity |
| 裝備 | 開局取得「太空人工具包 spacer kit」；需要確認有沒有某樣東西時做 *Check Your Gear* |

### 影響 Impacts

| 類別 | 影響 | 說明 |
|------|------|------|
| 不幸 Misfortunes | 負傷 Wounded、動搖 Shaken、準備不足 Unprepared | 可清除；標記時不能回復對應狀態條 |
| 持久影響 Lasting Effects | 永久傷害 Permanently Harmed、心理創傷 Traumatized | 永久 |
| 重擔 Burdens | 注定 Doomed、受折磨 Tormented、負債 Indebted | 完成對應任務才能清除 |
| 載具問題 Vehicle Troubles | 受損 Battered、受詛 Cursed | 只在搭乘該載具時計入；受詛是指揮載具的永久影響 |

## 5. 角色創建（待與使用者確認）

1. 與全隊一起完成「真相」練習，定義你的熔爐（歷史、科技、社群、生命、超自然能力等類別）
2. 分配屬性 3、2、2、1、1
3. 生命、精神、補給各 5；動能 +2（上限 10、重置 +2）
4. 選兩項**路徑**資產，構想背景故事
5. 立下**背景誓言**
6. 取得全隊共用的 **STARSHIP** 指揮載具並命名
7. 再選一項資產（夥伴、模組、支援載具或路徑）
8. 構想外觀、個性，取名與呼號（callsign）
9. 設定起始地點，對第一個任務立下鐵誓

## 6. 主持要點

- Starforged 的招式分類：進場、冒險、任務、連結、探索、戰鬥、承受、臨界、復原、傳承、命運（與 Sundered Isles 相同，招式名稱見 `sundered-isles.md`）。
- 戰鬥以「掌握主動 in control／身處險境 in a bad spot」描述位置，取代經典版的主動權。
- 探索用「遠征 Expedition」進度條，途中在「途經點 waypoint」做 *Explore a Waypoint*，有重大發現時 *Make a Discovery*。
- 神諭表未收錄；需要時用經典版的 `action`＋`theme` 替代，並依科幻語境詮釋。

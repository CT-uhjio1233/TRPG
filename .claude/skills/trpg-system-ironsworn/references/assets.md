# Ironsworn 經典版資產清單

> 依 Ironsworn Assets Master Set（© Shawn Tomkin，CC BY 4.0，2025 年授權更新版）整理。此處只列名稱、前提與核心效果的一句話摘要；完整能力文字請看原資產卡。
> 開局選 3 項。每項資產有 3 個能力：第一個（●）取得時就有，其餘（○）花 2 經驗逐一升級。新資產花 3 經驗。
> 「有前提」的資產（例如「一旦你殘缺……」）在劇情滿足前提後才能取得。

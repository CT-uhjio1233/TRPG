# 戰役種子：星見雅——穿越異世界的至高帝皇

> 依使用者的角色設定檔（「新增 Text Document」）與 v2.0 補充說明整理。設定檔的內容照原意保留；標示「范恩建議」的部分是為了讓這個種子能在本模擬系統中開場而補上的，使用者可以隨時覆寫。

## 1. 主角設定（使用者的原設定）

| 欄位 | 內容 |
|------|------|
| 名字 | 星見雅 |
| 性別／年齡 | 男／20 歲（穿越前是現代地球的大學生） |
| 種族 | 人類 |
| 職業 | 戰錘 40K 至高帝皇 |
| 戰鬥定位 | 無（本人沒有戰鬥能力，一切戰力來自召喚） |
| 性格 | **被迫害妄想、偏執防衛**：認為任何接近的人都可能是敵人。**冷酷果斷**：處事直接，不拖泥帶水、毫不猶豫。**極端自信**：擁有至高帝皇任務與召喚系統 |
| 系統 | 至高帝皇任務與召喚系統（設定檔寫 v1.1；本 skill 採 v2.0 規則＋v1.1 數值，見 `summon-system.md` §12） |

**開場（原設定）：** 靈魂穿越到一名貴族私生子身上。原身因出身被家族鄙視、邊緣化；母親被家族成員逼死，無人理會；原身隨後被流放到偏僻小鎮等死。開場時他正在前往小鎮的路上，因過度傷心加上水土不服而病死——穿越者就在這一刻醒來。然後「開始第一章」。

**世界（v2.0）：** D&D 世界，規則用 `trpg-system-dnd5e`。世界的居民一開始完全不理解戰錘 40K 的單位與裝備（觀感見 `factions.md` 末節）。

## 2. 在本模擬系統中開局

**扮演權：** 星見雅是**使用者的角色**。他的妄想、冷酷與自信由使用者決定怎麼演；范恩只描寫世界與 NPC，**不替他產生內心獨白或決定**（`trpg-simulator` 紅線 2）。范恩能做的是讓 NPC 的動機曖昧而一致——有人真的想害他，有人只是看起來可疑，讓偏執有時救命、有時誤傷。

**稱呼：** 為避免和隊友「小雅」混淆，敘事中稱主角為「星見」，或依 NPC 身分稱「少爺」「那個私生子」。

**開局時與使用者確認（范恩建議的預設值）：**

| 項目 | 預設 |
|------|------|
| 世界 | D&D 5e 的自創王國（也可改用 `trpg-system-dnd5e` 的被遺忘國度） |
| 主角的肉體 | D&D 5e 人類，屬性由使用者依 `trpg-system-dnd5e` §2 三選一決定；**無職業**，生命值 ＝ 4 ＋ 體質調整值；開場帶著重病（1 級力竭，休養痊癒前不會消除） |
| 系統起始值 | 魔力上限 50、專注穩定度 10、1 條專注通道、EP 0、沒有任何技能卡 |
| 第一個任務 | 系統覺醒時派發「活下去」：抵達流放地並存活 24 小時；獎勵為訓練池單抽券一張 |
| 版本口徑 | v2.0 規則＋v1.1 數值；崩潰掉線順序採「最近啟動先斷」 |
| EP 刻度 | 依 `summon-system.md` §9 的建議刻度 |

**隊友怎麼加入（范恩建議）：** 系統只屬於使用者。四位隊友依 `trpg-party` 的共同協議，**各自用 D&D 5e 建立本地角色**（職業、動機由他們自己選），范恩安排他們在流放途中或小鎮裡與星見交會——押送的護衛、鎮上的冒險者、教會的見習修士、被同一個家族迫害的人。主角的多疑正好給隊友一個「如何贏得信任」的長線。

## 3. 第一章的幕後素材（范恩建議，交給 `trpg-fane-storywriter`）

- **開場畫面（破題法）：** 泥濘山路上的破舊馬車，雨打在篷布上；原身的屍體剛冷，穿越者在高燒與陌生的記憶洪流中醒來。車外兩名家族護衛在低聲討論「還有多久才死」。
- **系統覺醒：** 以框線區塊呈現系統介面（格式見 `summon-system.md` §11），第一則訊息就是任務「活下去」。
- **第一個威脅（任選或組合）：** 護衛奉命讓他「病死在路上」；山賊攔路；流放地的領主不想收這個麻煩。第一次抽卡多半只有 R1–R2——一小隊衛兵、幾頭芬里斯狼或一群奴工，就足以翻轉這個場面，同時讓本地人第一次見識「憑空出現的士兵」。
- **長線：** 母親之死與家族的真相（主線任務鏈）；召喚能力被發現後各方勢力的拉攏與獵殺；D&D 世界的邪教與惡魔帶來的**污染度**，觸發系統的「淨化」任務並開啟渾沌池。
- **節奏：** 每日循環任務讓召喚與成長穩定發生；主線任務在每章結尾推進一次（`trpg-fane-pacing`）。

## 4. 帳本需要記錄的欄位（交給 `trpg-fane-ledger`）

- 帝皇點數 EP、抽卡券、各卡池的保底計數（R4／R5）
- 已擁有的技能卡與同步度 Lv
- 魔力上限、目前魔力、魔力回復；專注穩定度 FOC、目前負荷 Load（只記帳，不在敘事中報數）；通道數
- 每張卡的冷卻或死亡冷卻結束時間
- 進行中的系統任務（目標、地點、時限、限制、獎勵、懲罰）
- 污染度、被封鎖的陣營卡池、費用上升等懲罰狀態
- 目前在場的召喚單位、剩餘秒數、已產生的戰利品

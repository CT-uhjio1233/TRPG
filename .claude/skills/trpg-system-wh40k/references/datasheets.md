# 資料卡判讀、稀有度歸類與跨世界裁定

> §1 依使用者的《戰錘 40000 基礎規則》（9 版正體中譯）與各聖典資料卡整理；§2 的歸類準則、§4 的換算與 §5 的裁定法是**范恩為本系統訂的裁定工具**，原書沒有，使用者可以要求調整。

## 1. 資料卡怎麼讀（40K 10 版）

| 欄位 | 意義 |
|------|------|
| **M** 移動 | 每回合移動距離（吋）；「20+"」是飛行器 |
| **T** 韌性 | 越高越難被致傷 |
| **SV** 豁免 | 護甲擲骰目標（2+ 最好）；另有**無敵豁免**（不受穿甲影響）與**不覺疼痛**（每點傷害再擲一次） |
| **W** 耐傷 | 生命值 |
| **LD** 領導力 | 士氣測試目標（2D6 ≥ LD） |
| **OC** 目標控制 | 佔領據點的份量 |
| 武器 **A／BS 或 WS／S／AP／D** | 攻擊次數／命中目標值／力量／穿甲／傷害 |

**攻擊流程：** 命中擲骰（D6 ≥ BS 或 WS）→ 致傷擲骰（比較 S 與 T：S ≥ 2T 為 2+、S > T 為 3+、S = T 為 4+、S < T 為 5+、S ≤ T/2 為 6+）→ 目標豁免（SV 加上 AP 的修正，無敵豁免不受 AP 影響）→ 造成 D 點傷害。

**其他格式：**
- **禁軍檔（9 版）：** 屬性為 M／WS／BS／S／T／W／A／Ld／Sv，並以戰力值 PL 計價（約 1 PL ≈ 20 點）。
- **黑暗之奴檔（西格瑪時代）：** 屬性為移動／保護／生命值／勇氣值，以分數計價；武器欄為射程／攻擊次數／命中／造傷／破甲／傷害。
- **帝國檔（帝國裝甲與傳奇）：** 單位以 A-編號索引並附點數。

## 2. 稀有度歸類準則（白名單 `cards.csv` 依此編排）

| 稀有度 | 典型資料卡 | 例 |

| **R2** | 動力甲小隊（W2、SV 3+）、輕型載具與運兵車（W ≤ 11）、騎兵、次要角色 | 灰色獵手、恐虐狂戰士、奇美拉、犀牛、政委、血肉獵犬 |
| **R3** | 終結者與重裝步兵、無畏機甲（W8 級）、中型戰車（W11–12）、多數具名英雄（W4–7 步兵或騎乘） | 兄弟會終結者、禁軍衛士、雷狼騎兵、地獄犬、背叛者卡恩 |
| **R4** | 重型戰車（W13–18）、惡魔機甲、大魔、惡魔親王、飛行炮艇、戰團長級英雄 | 黎曼魯斯、蘭德掠襲者、嗜血狂魔、涅墨西斯駭騎機甲、阿茲瑞爾 |

**例外與註記（已寫進 `cards.csv` 備註欄）：**
- 使用者 v1.1 的三張範例卡照原設定保留名稱；其中「嗜血騎獄」召喚的**顱骨主宰**在聖典中是 W6 的騎乘先鋒，本白名單依數據改列 **R3**。
- 「聖焰突擊」依使用者範例以 **5 人模板**登場（聖典編制是 10–20 人）。
- 黑色聖堂、黑暗天使、禁軍的檔案沒有 R1 級單位，禁軍也只有一張 R2；抽到時依 `summon-system.md` §8 的「陣營缺卡」規則處理。
- 黑色聖堂、太空野狼、灰騎士沒有超重型，由各自的至高領袖（赫爾布雷徹、洛根、得萊戈）擔任 R5「傳奇」。

**新增卡片：** 在 `cards.csv` 追加一列（陣營、稀有度、技能名、召喚單位、類型、規模、索引、備註），類型必須是 步兵／菁英／角色／載具／怪獸／超重型 之一。`summon.py` 會自動讀入。

## 4. 對照 D&D 5e 的威脅刻度（范恩的敘事校準）

當召喚單位與 D&D 世界的生物交手時，用下表判斷「這一仗在誰的量級」。這是敘事校準，不是換算公式：

| 稀有度 | 大致相當於 D&D 的對手 | 對 D&D 冒險隊的意義 |
|--------|----------------------|--------------------|
| R1 | CR 1/8–1 的士兵、衛兵、老兵小隊 | 1–4 級隊伍的可靠火力；對付強盜、哥布林綽綽有餘 |
| R2 | CR 2–5 的精銳小隊或巨獸（食人魔、巨魔級） | 可以正面擊潰一支小型軍隊 |
| R3 | CR 6–10（年輕龍、石像魔像、強大的惡魔） | 足以扭轉一場領主之間的戰鬥 |
| R4 | CR 11–16（成年龍、巫妖以下的大敵） | 一國軍隊的決戰手段 |
| R5 | CR 17 以上（遠古龍、惡魔領主、神話級存在） | 改寫國家版圖的戰略武器 |

40K 的火力優勢很大（爆矢槍、激光炮能在射程外擊穿 D&D 的全身鎧），但**在場時間只有幾十秒到幾分鐘**，而且召喚者本人極度脆弱——戰役的張力來自這個落差。

## 5. 跨世界戰鬥的裁定法（本系統的補充規則）

1. **同量級或召喚單位高一級：** 以敘事結算，只在結果真正不確定時擲一次 `roll.py` 的 d20 檢定。
2. **量級比較：** DC 基準 10；召喚單位每高對手一級，DC −5；每低一級，DC +5。成功＝達成戰術目標；失敗＝付出代價（單位受損、時長耗盡、召喚者受傷而增加負荷）。
3. **召喚者本人**遵守 D&D 5e 規則（生命值、豁免、傷害）；他受的輕傷／重傷同時觸發負荷（`summon-system.md` §5）。
4. **D&D 的魔法** 可以影響召喚單位（魅惑、控制等由范恩依量級判斷有無效果），但**無法奪走指揮權**：忠誠口徑高於一切。反魔法力場與驅散魔法是否會打斷召喚，開局時由范恩與使用者確認。
5. 所有擲骰仍批次交給 `trpg-fane-rules` 的 `roll.py`；抽卡與任務類型交給 `summon.py`。

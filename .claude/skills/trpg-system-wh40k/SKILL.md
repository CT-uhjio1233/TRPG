# 戰錘 40K｜至高帝皇任務與召喚系統

> 本 skill 是 `trpg-simulator` 的規則系統模組，供范恩的 `trpg-fane-rules`、`trpg-fane-storywriter`、`trpg-fane-ledger`、`trpg-fane-visuals` 引用。
> 使用者的檔案有三類：自創的**至高帝皇任務與召喚系統**（v1.1、v2.0）與角色種子；戰錘 40K 的**兵棋聖典**中譯（10 版為主，禁軍為 9 版，黑暗之奴為西格瑪時代）；以及基礎規則、點數手冊。聖典受版權保護，本 skill 只保留單位名稱、數據重點與改寫的背景摘要，不轉載原文。

## 1. 這個 skill 的兩種用法

| 用法 | 說明 |
|------|------|
| **至高帝皇戰役**（主要） | 使用者扮演擁有召喚系統的「至高帝皇」，在 **D&D 5e 世界**冒險；世界與主角肉體的規則用 `trpg-system-dnd5e`，召喚、抽卡、任務用本 skill。戰役種子見 `references/campaign-seed.md` |
| **40K 素材庫** | 其他戰役需要 40K 的陣營、單位或背景時查閱 `references/factions.md`、`references/datasheets.md` |

使用者的檔案**沒有 40K 的角色扮演規則書**（例如 Wrath & Glory、Dark Heresy），只有兵棋規則。若使用者想直接在 40K 宇宙裡跑團，范恩在初始化時建議借用一套通用系統（CoC 7e 的百分骰或 D&D 5e 的 d20），並以本 skill 的資料卡作為威脅量級參考。

## 2. 召喚系統速查卡

完整規格見 `references/summon-system.md`（v2.0 規則為準，v1.1 提供數值；差異表在 §12）。

| 項目 | 規則 |
|------|------|
| 抽到什麼 | 召喚技能卡（一卡一種單位），不是單位本身 |
| 在場時長 | 預付魔力：R1 5／R2 4／R3 3／R4 2／R5 1 秒每 MU × 類型係數（步兵 1、菁英 0.9、角色 0.8、載具／怪獸 0.7、超重型 0.5） |
| 專注 | 基礎 FOC 10；負荷 ≥ FOC 即崩潰，所有召喚靜默消散。輕傷 +3、重傷 +6、劇烈運動每 2 秒 +1、時長懲罰每 30／20／10 秒 +1 |
| 多重召喚 | 通道 n：時長效率 0.85^(n−1)、常駐負荷 2(n−1)、時長懲罰間隔 ÷n；2／3／4 通道需 FOC 12／16／20 與試煉、EP |
| 冷卻 | 30／60／120／180／300 秒；戰死則為兩倍（v2.0） |
| 卡池 | 訓練 R2 上限 50 EP｜前線 R3 75｜焦點 R4 100（焦點陣營 ×2）｜傳奇、活動 R5 150；十連 ×9.5 |
| 機率與保底 | R1 54／R2 24／R3 14／R4 7／R5 1%，依上限等比重分；30 抽保 R4、120 抽保 R5 |
| 抽卡流程 | 稀有度 → 1D10 陣營 → 該陣營該稀有度的卡 |
| 同步度 | 重複抽到：Lv1 時長 +10%、Lv3 死亡冷卻 −30%、Lv5 FOC +3 且冷卻 −30% |
| 忠誠 | 所有召喚單位無條件服從至高帝皇，渾沌陣營也不例外 |
| 生成 | 視線內 30 m 空位；室內與城市限制大型載具與飛行器（空間不足時施放被拒絕、不進冷卻）；無光無聲出現與消失 |
| 裝備 | 單位撤離時裝備一併消失；戰利品留在現實 |

## 3. 擲骰與計算：summon.py

抽卡與任務類型是隨機結果，**一律由 `scripts/summon.py` 產生**（P1 亂數客觀性）；時長與冷卻也用它計算，避免心算出錯。D&D 世界的檢定照常用 `trpg-fane-rules` 的 `roll.py`。

```bash
# 抽卡：卡池 training／frontline／focus／legend／event（亦可用中文：訓練、前線、焦點、傳奇、活動）
python3 <本 skill 目錄>/scripts/summon.py pull training --ep 120
python3 <本 skill 目錄>/scripts/summon.py pull focus --focus 星界軍 --featured 黎曼魯斯戰鬥坦克 --pity R4=12 --ep 480
python3 <本 skill 目錄>/scripts/summon.py pull legend --ten --pity R4=3,R5=57 --ep 2000

# 時長、冷卻與負荷（可用 --card 技能名，或 --rarity 與 --type）
python3 <本 skill 目錄>/scripts/summon.py dur --card 鐵洪投影 --mu 30 --channels 2 --sync 1 --mp-max 50

# 系統任務類型、白名單查詢、卡池機率表
python3 <本 skill 目錄>/scripts/summon.py mission
python3 <本 skill 目錄>/scripts/summon.py list --faction 禁軍 --rarity R4
python3 <本 skill 目錄>/scripts/summon.py rates focus --focus 灰騎士
```

- 參數有誤時整批不擲出。保底計數、EP 餘額從帳本讀入、結果寫回帳本。
- `--legacy-death` 改用 v1.1 的小時制死亡冷卻；`--no-type` 關閉類型係數；`--overcast` 套用「超載施放」專長。
- 輸出的 `[召喚]`、`[時長]`、`[任務]` 區塊依 `trpg-fane-rules` 的擲骰展示格式放在回合末的判定區，不寫進 IC 敘事。

## 4. 回合中的召喚流程

1. **宣告**：使用者指定技能卡與登場位置。范恩核對帳本：擁有這張卡、不在冷卻、有空閒通道、魔力足夠。
2. **空間判定**：地形是否容得下（載具要開闊平地、飛行器要空域、超重型要大型開闊地）。不行就拒絕施放，不進冷卻。
3. **計算時長**：`summon.py dur`，扣除魔力，記下結束時間。
4. **敘事**：無光無聲地出現；本地人的反應依 `factions.md` 末節。單位依使用者的命令行動，量級衝突依 `datasheets.md` §5 裁定。
5. **負荷**：每次輕傷、重傷、衝刺、恐懼事件都在帳本記負荷；敘事只用體感描寫，不報數字。
6. **收尾**：時間到、專注崩潰或取消 → 靜默消散 → 裝備消失、戰利品留下 → 記冷卻（戰死則死亡冷卻）。
7. **系統任務**：由 `trpg-fane-storywriter` 派發與結算；發放 EP、抽卡券與成長。

**系統訊息**是故事中只有主角看得見的元素（不是模擬器術語），用框線區塊呈現，格式見 `summon-system.md` §11。

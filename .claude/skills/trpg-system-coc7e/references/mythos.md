# 克蘇魯神話與洛夫克拉夫特鄉野

> 依規則書第 2 章「洛夫克拉夫特與克蘇魯神話」的概念整理，並補充洛夫克拉夫特原作（公有領域）中的常見元素。具體的神話生物數據與咒語不在使用者可讀的文字範圍內，需要時請 KP（范恩）依原書或自行設計，並遵守 `trpg-fane-narrator` 的「不可名狀」原則。

## 核心概念

- **宇宙的冷漠：** 人類只是浩瀚、冷漠宇宙中微不足道的偶然。神話存在不一定邪惡，而是根本不在乎人類。
- **知識即危險：** 越接近真相，心智越難承受。這就是理智機制的意義——調查員贏得的每一分真相都有代價。
- **勝利是暫時的：** 調查員通常只能阻止一個儀式、封印一扇門、延後一場災難，而不是消滅神明。

## 神話存在（常見名稱）

| 分類 | 代表 |
|------|------|
| **外神 Outer Gods** | 阿撒托斯 Azathoth（宇宙中心盲目癡愚之神）、猶格·索托斯 Yog-Sothoth（門與鑰）、奈亞拉托提普 Nyarlathotep（伏行之混沌，化身千面，常以人形與人類打交道）、莎布·尼古拉絲 Shub-Niggurath（孕育千子的黑山羊） |
| **舊日支配者 Great Old Ones** | 克蘇魯 Cthulhu（沉睡於太平洋底的拉萊耶城）、哈斯塔 Hastur（不可言說者）、伊塔庫亞 Ithaqua（風行者）、札特瓜 Tsathoggua 等 |
| **神話種族** | 深潛者 Deep Ones（與人類混血的海中種族）、米·戈 Mi-Go（來自猶格斯的真菌甲殼生物）、遠古種族 Great Race of Yith（跨越時間交換心智）、古老者 Elder Things 與其奴僕修格斯 Shoggoth、食屍鬼 Ghouls、拜亞基 Byakhee、廷達洛斯獵犬 Hounds of Tindalos |

描寫原則：**不要直接說出名字與本質**。讓玩家看到可觀測的細節（腥味、鱗片、不合比例的肢體、錯誤的幾何角度），名字只在典籍、邪教徒口中或事後的調查中出現。

## 禁忌典籍

《死靈之書 Necronomicon》、《無名祭祀書 Unaussprechlichen Kulten》、《伊波恩之書 Book of Eibon》、《拉萊耶文本 R'lyeh Text》、《蠕蟲之秘密 De Vermis Mysteriis》等。閱讀典籍的流程：花時間研讀 → 理智損失 → 克蘇魯神話技能增加 → 可能習得咒語。

## 洛夫克拉夫特鄉野（麻薩諸塞州，1920 年代）

| 地點 | 特色 |
|------|------|
| **阿卡姆 Arkham** | 陰鬱的大學城，**密斯卡托尼克大學**所在地，其圖書館收藏禁忌典籍，是調查員的起點與資源中心 |
| **敦威治 Dunwich** | 偏僻、衰敗的山村，近親通婚與山丘上的石圈（使用者的調查員手冊第 2 章收錄了《敦威治恐怖事件》） |
| **印斯茅斯 Innsmouth** | 沒落的漁港，居民有著「印斯茅斯長相」，與深潛者的秘密交易 |
| **金斯波特 Kingsport** | 古老的海港，迷霧與夢境的邊界 |

## 1920 年代背景（「咆哮的二十年代」）

- 一戰結束不久，許多調查員是退伍軍人（對應「戰場經歷包」）。
- 美國禁酒令時期：私酒、地下酒吧、黑幫——罪犯與警察職業的舞台。
- 科技：電話、電報、汽車、無聲電影轉向有聲電影、早期飛機；沒有網路與手機，資訊得靠圖書館、報社檔案與人脈。
- 社會：階級、種族與性別的偏見普遍存在；范恩呈現時代氛圍時，不需要替角色附加道德說明（遵守 `trpg-simulator` 紅線 4），但也不應讓歧視成為對使用者的冒犯——必要時用安全閥（`trpg-fane-session`）確認界線。

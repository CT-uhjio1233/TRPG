# 克蘇魯的呼喚 第七版（CoC 7e）

> 本 skill 是 `trpg-simulator` 的規則系統模組，供范恩的 `trpg-fane-rules`、`trpg-fane-storywriter`、`trpg-fane-crisis`、`trpg-fane-visuals` 引用。
> 使用者的《守秘人規則書》與《調查員手冊》是 Chaosium 官方書的非官方簡體中譯本；本 skill 以正體中文（台灣用語）改寫整理，技能與術語沿用中譯本譯名並轉為正體。書中文字受版權保護，這裡只保留規則摘要，不轉載原文。
> 本模擬系統的原始設計（SAN、恐懼症、心智崩潰雙軌敘事）本來就以 CoC 為範本，本 skill 補足完整規則。

## 1. 核心機制

**擲 1d100，結果 ≤ 技能值或屬性值即成功。**

| 結果 | 條件 |
|------|------|
| **大成功** | 01 |
| **極難成功** | ≤ 技能值的 1/5 |
| **困難成功** | ≤ 技能值的 1/2 |
| **常規成功** | ≤ 技能值 |
| **失敗** | > 技能值 |
| **大失敗** | 技能值 < 50 時 96–100；技能值 ≥ 50 時 100 |

- **難度：** 守秘人（KP）依情境要求常規、困難或極難成功，而不是加減技能值。對抗 NPC 時，對方技能 ≥ 50 通常要求困難，≥ 90 要求極難。
- **獎勵骰／懲罰骰：** 十位數多擲一顆，取較好／較差的結果；兩者互相抵消，最多各兩顆。
- **對抗檢定：** 雙方各擲，比較成功等級；等級相同時技能較高者勝（戰鬥有特殊規則，見 `references/combat-sanity.md`）。
- **聯合檢定：** 一次擲骰同時對照兩項技能。
- **孤注一擲 Pushing：** 失敗後，玩家說明角色如何加倍努力，經 KP 同意可重擲一次。**孤注一擲再失敗，後果會比一般失敗嚴重得多**，KP 可事先預告代價。戰鬥、理智、幸運檢定不能孤注一擲。
- **幸運：** 幸運檢定用於「運氣好不好」的情境。可選規則：擲骰後花幸運點把結果降到成功（1 點降 1），但不能用於幸運檢定、理智檢定與理智損失、傷害擲骰，也不能與孤注一擲並用。
- **KP 決定是否擲骰：** 調查員的專長範圍內、沒有時間壓力的行動，直接成功；只有在失敗有意義時才擲。

擲骰一律用 `trpg-fane-rules` 的腳本，`@技能值` 會自動判定成功等級：

```bash
python3 <trpg-fane-rules 目錄>/scripts/roll.py \
  "使用者-圖書館使用:1d100@65" "小宇-偵查:1d100b1@60" "使用者-理智:1d100@55" "?使用者-理智損失:1d6"
```

## 2. 調查員創建

1. **擲屬性**（一次批次擲完）：

| 屬性 | 擲法 | 用途 |
|------|------|------|
| 力量 STR | 3D6×5 | 肌力、近戰傷害 |
| 體質 CON | 3D6×5 | 耐力、生命值、抗毒抗病 |
| 體型 SIZ | (2D6+6)×5 | 身材、生命值、傷害加值 |
| 敏捷 DEX | 3D6×5 | 靈巧、行動順序、閃避 |
| 外貌 APP | 3D6×5 | 外表與魅力 |
| 智力 INT | (2D6+6)×5 | 推理、興趣技能點、靈感 |
| 意志 POW | 3D6×5 | 意志力、理智、魔法值 |
| 教育 EDU | (2D6+6)×5 | 正規知識、職業技能點、母語 |
| 幸運 Luck | 3D6×5 | 運氣 |

   腳本寫法：`"STR:3d6*5" "SIZ:(2d6+6)*5" …`。

2. **年齡調整**（15–90 歲，不疊加）：

| 年齡 | 調整 |
|------|------|
| 15–19 | 力量與體型合計 −5；教育 −5；幸運擲兩次取高 |
| 20–39 | 教育增強檢定 1 次 |
| 40–49 | 教育增強檢定 2 次；力量、體質、敏捷合計 −5；外貌 −5 |
| 50–59 | 教育增強檢定 3 次；合計 −10；外貌 −10 |
| 60–69 | 教育增強檢定 4 次；合計 −20；外貌 −15 |
| 70–79 | 教育增強檢定 4 次；合計 −40；外貌 −20 |
| 80–89 | 教育增強檢定 4 次；合計 −80；外貌 −25 |

   **教育增強檢定：** 擲 1d100，大於目前教育值則教育 +1d10（上限 99）。

3. **衍生屬性：**
   - **生命值** ＝（體質＋體型）÷ 10，捨去小數
   - **魔法值** ＝ 意志 ÷ 5
   - **理智值** ＝ 意志；**理智上限** ＝ 99 − 克蘇魯神話技能
   - **傷害加值與體格**（力量＋體型）：2–64 → −2／−2；65–84 → −1／−1；85–124 → 0／0；125–164 → +1D4／1；165–204 → +1D6／2；205–284 → +2D6／3；之後每 80 點再 +1D6／+1。傷害加值不用於槍械。
   - **移動力 MOV**：敏捷與力量都小於體型 → 7；兩者之一 ≥ 體型或三者相等 → 8；兩者都大於體型 → 9。40 多歲 −1、50 多歲 −2、60 多歲 −3、70 多歲 −4、80 多歲 −5。

4. **選擇職業**（`references/occupations.md`）：職業技能點（多為 教育×4，或 教育×2＋某屬性×2）分配到該職業的八項本職技能；**信用評級**必須落在職業的範圍內。
5. **興趣技能點** ＝ 智力×2，分配到任何技能（克蘇魯神話除外）。技能基礎值見 `references/skills.md`。
6. **背景故事：** 形象描述、思想與信念、重要之人、意義非凡之地、寶貴之物、特質；至少一項標記為「關鍵連結」（失去時會重創理智的那一項）。
7. **可選：經歷包**（KP 同意、每人至多一個），讓調查員帶著戰爭、警務、犯罪、醫務或神話經歷開局，詳見 `references/occupations.md`。
8. **裝備與資產：** 依信用評級決定生活水準、現金與資產。

角色卡依 `trpg-fane-visuals` 格式輸出，屬性區列九項屬性與其 1/2、1/5 值，資源區列生命值、魔法值、理智值、幸運、傷害加值、體格、移動力。

## 3. 戰鬥、理智與追逐

細節見 `references/combat-sanity.md`。要點：

- **行動順序依敏捷**（已拔槍瞄準者視為敏捷 +50）。
- **近戰：** 攻擊方擲格鬥，防禦方選擇**閃避**或**反擊**，比較成功等級。極難成功時，貫穿武器造成**貫穿**（最大傷害＋再擲一次武器傷害），其他武器造成最大傷害。
- **槍械：** 目標不能閃避子彈（只能撲向掩蔽）；近距離有獎勵骰、遠距離需困難或極難成功。
- **重傷：** 一次受到 ≥ 最大生命值一半的傷害。生命值 0 且有重傷 → 瀕死，每輪擲體質，失敗即死亡，需要急救穩定、醫學治療。
- **理智檢定：** 1d100 ≤ 目前理智值，依結果扣除「成功損失／失敗損失」（例：0/1D6）。單次損失 ≥ 5 且通過智力檢定 → **臨時瘋狂**；一天內損失 ≥ 目前理智的 1/5 → **不定期瘋狂**；理智歸零 → **永久瘋狂**。發作時依 `trpg-fane-crisis` 進行雙軌敘事。
- **追逐：** 以移動力與體質速度檢定建立追逐，在一連串「地點」上以行動與危險障礙判定追上或甩掉。

## 4. 技能成長

- 遊戲中在**有意義的情況下**首次成功使用某技能時，打勾（幸運、信用評級、克蘇魯神話不能打勾）。
- 劇本結束或 KP 指定的成長期：對每個打勾的技能擲 1d100，**大於目前技能值**（或 ≥ 96）即該技能 +1d10。
- 技能首次達到 90 以上時，理智 +2D6。

## 5. 世界與劇本

- `references/mythos.md`：克蘇魯神話的基本概念、舊日支配者與外神、神話生物、禁忌典籍、洛夫克拉夫特鄉野（阿卡姆、敦威治、印斯茅斯、密斯卡托尼克大學），以及 1920 年代的時代背景。
- **原創劇本：** `trpg-fane-storywriter` 的「現實世界背景」分支正是為 CoC 設計；CoC 的主角是**普通人**，比 D&D 脆弱得多，調查線索、社會資源與撤退選項比戰鬥能力更重要。
- **已發行劇本：** 使用者的資料夾中沒有 CoC 模組；若要跑官方劇本，依 `trpg-fane-storywriter` §1 處理。

## 6. 由范恩主持 CoC

- 范恩在 CoC 中稱為**守秘人 Keeper（KP）**。
- **線索的清晰度：** 關鍵線索不應被單次擲骰鎖死——失敗可以代表「找到了但付出代價」或「被別人先拿走」，而不是劇情卡死；但「世界充滿惡意」條款依然適用：漏看的線索會在之後變成致命劣勢。
- **理智是資源，也是故事：** 每次理智損失都要依 `trpg-fane-narrator` 渲染，並登記進帳本；恐懼症與躁狂症在之後的相關刺激前必須展現。
- **隊友的職業傾向**（開局時仍由他們「自己選」）：小宇偏好教授、科學家或圖書館管理員、阿凱偏好記者、運動員或事務所偵探、小雅偏好作家、藝術家或業餘藝術愛好者、子豪偏好醫生、護士或司機。

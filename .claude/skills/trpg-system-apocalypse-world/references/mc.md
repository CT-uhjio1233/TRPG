# 司儀 MC：議程、原則、招式、戰線與威脅

> 「戰線與威脅」依使用者的擴展資料冊（Fundamental Scarcities & Fronts）整理；「議程、原則、MC 招式、威脅衝動」出自核心書 MC 章節，使用者的核心書文字檔未擷取到該章，以下依范恩對核心規則的記憶整理，細節以原書為準。

## 議程 Agenda

- 讓末日世界顯得真實
- 讓角色的人生不無聊
- 邊玩邊找出會發生什麼（不預設結局）

## 永遠要說 Always Say

原則要求的、規則要求的、你的準備要求的、誠實要求的。

## 原則 Principles

- 大量吐出末日細節（Barf forth apocalyptica）
- 對角色說話，而不是對玩家說話
- 做出你的招式，但要誤導；做出你的招式，但永遠不說出它的名字
- 透過準星看待一切（任何東西都可能受威脅、被奪走、被摧毀）
- 為每個人取名字，讓每個人都有人性
- 提出挑釁的問題，並依答案發展（本系統中改由 NPC 或隊友提出，見 SKILL.md §6）
- 以亂來與間歇性的獎賞回應
- 做角色的粉絲
- 也要思考鏡頭外發生的事
- 有時放棄做決定（交給骰子、倒數時鐘或威脅的衝動）

## MC 招式

玩家失手、看著你等你反應、或給你大好機會時做出。軟招式預告危險、給玩家反應的空間；硬招式直接造成後果。

- 把他們分開
- 抓住某人
- 讓某人陷入困境
- 依既定事實交換傷害
- 宣告鏡頭外的壞事
- 宣告將至的壞事
- 依既定事實造成傷害
- 拿走他們的東西
- 讓他們付出代價才能得到
- 啟動他們東西的缺點
- 告訴他們可能的後果，然後詢問（本系統中以陳述句呈現後果）
- 提供機會，附帶或不附帶代價
- 讓他們的招式反噬
- 做出一個威脅招式（來自你的戰線）

## 戰線 Fronts（擴展資料冊）

戰線是一組相互關聯的威脅，全部源自同一個威脅情勢。**核心是一項根本匱乏，終點是它將帶給世界的地獄未來。**

**建立戰線：**
1. **根本匱乏**（選一，並標在匱乏地圖上）：飢餓 hunger、口渴 thirst、無知 ignorance、恐懼 fear、腐朽 decay、絕望 despair、嫉妒 envy、野心 ambition
2. **名稱**：直接、描述性的名字
3. **地獄未來／議程**：一兩句話，寫出如果沒人阻止，它會造成的地獄
4. **描述與角色群**：至少 1 個、至多 3–4 個表現這項匱乏、推向地獄未來的威脅
5. **關鍵問題 stakes questions**：你對這條戰線會如何發展的疑問（聚焦在第一線的角色）
6. **總倒數時鐘**：反映戰線朝地獄未來推進的進度（可遊戲中再加）

**家園戰線 Home front：** 沒有匱乏、沒有地獄未來、沒有總倒數；收納不屬於其他戰線的基本威脅，以及不附屬任何威脅的通用自訂招式。
- 角色所在之處 → 建成「地景」
- 角色的幫眾 → 建成「粗人」
- 角色的其他 NPC → 建成「粗人」，外加一個「怪物」和／或一個「想當軍閥的人」
- 角色的載具 → 建成「載具」
- 當地居民 → 建成一項「苦難」

## 威脅 Threats

**建立威脅：** 選種類 → 命名 → 抄下衝動 → 描述 → 列出角色群、關鍵問題，需要時建立自訂招式或倒數時鐘。

| 種類 | 子類（擴展資料冊） | 衝動（核心書，依記憶） |
|------|-------------------|----------------------|
| **軍閥 Warlords** | 奴隸販子、蜂后、先知、獨裁者、收藏家、頭狼 | 奴役並販賣人口、吞噬與蜂擁、譴責與推翻、控制、擁有、狩獵與支配 |
| **怪物 Grotesques** | 食人者、變種人、痛苦成癮者、疾病載體、心靈操控者、逆生之物 | 渴求飽足、渴求補償、渴求痛苦、渴求接觸、渴求掌控、渴求混亂與一切的毀滅 |
| **苦難 Afflictions** | 疾病、處境、習俗、妄想、犧牲、屏障 | 使人口飽和感染、讓人暴露於危險、宣揚並合理化暴力、支配人的選擇、讓人失去所愛、讓人貧困 |
| **粗人 Brutes** | 獵群、享樂者、執法者、邪教、暴民、家族 | 欺凌弱者、消耗他人資源、欺凌出頭者、欺凌並吸收人、暴動與獵殺代罪羔羊、團結保護自己人 |
| **地景 Landscapes** | 監獄、孕育坑、熔爐、海市蜃樓、迷宮、堡壘 | 困住、滋生壞事、吞噬、引誘並背叛、阻礙通行、拒絕進入 |
| **地形 Terrain** | 懸崖、牆、懸垂、暴露之處、移動的地面、破碎的地面 | （第二版新增，衝動未收錄，依地形性質自行決定） |
| **載具 Vehicles** | 依性格組合：兇猛、狡猾、大膽、狂野、惡毒、無情等 | 依性格而定 |

## 倒數時鐘

與傷害時鐘相同的六段：3:00、6:00、9:00、10:00、11:00、12:00。每當威脅得逞、或角色錯失阻止它的機會，就往前推一格；到 12:00 時地獄未來降臨。登記在 `trpg-fane-ledger` 的 NPC 旗標欄。

## 資源與名字

擴展資料冊附有 NPC 名字清單（Tum Tum、Gnarly、Dremmer、Balls、Rothschild、Dustwich……）與資源清單（肉、鹽、穀物、飲水、熱水、庇護、自由、燃料、安全、時間、醫療用品、情報、汽油、武器、勞力、技術、牆、機械、人脈、書……）。為威脅取名時，直接從末日世界風格的名字中挑選，並讓資源成為爭奪的核心。

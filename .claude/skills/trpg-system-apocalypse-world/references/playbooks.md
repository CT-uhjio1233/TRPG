# 末日世界角色手冊

> 依使用者檔案中的手冊介紹整理摘要（非原文）。中文名為本 skill 自譯。

## 核心書（第一版）

| 手冊 | 定位 |
|------|------|
| **天使 The Angel** | 末日裡的醫者。神早已離去、同伴靠不住，躺在塵土裡腸子流滿地時，你只能指望天使。專精治療、穩定傷勢，可以用觸碰治癒 |
| **戰姬 The Battlebabe** | 危險而迷人的戰鬥者，你明知該低頭走開卻移不開視線。以冷靜與身法戰鬥，徒手也有護甲 |
| **腦人 The Brainer** | 詭異的心靈控制者：傀儡絲、冰冷的心、破碎的眼睛，站在你的視野邊緣對你的腦袋低語。據點主最愛的「高雅擺設」 |
| **飛車黨頭目 The Chopper** | 世界什麼都缺，只有汽油和子彈夠多。你帶著一群摩托車幫眾，靠暴力在荒原上討生活 |
| **駕駛 The Driver** | 道路斷裂、城市孤立，地平線一片黑暗、沒有路通往那裡。你有車，你能去別人去不了的地方 |
| **槍手 The Gunlugger** | 法律與社會徹底崩壞，你的東西只有握在手裡時才是你的。最直接的暴力解決方案——有時顯而易見的做法就是對的 |
| **據點主 The Hardholder** | 沒有政府的世界裡，你統治一座據點：牆、人、資源、還有隨之而來的所有麻煩 |
| **邪教巫師 The Hocus** | 神明離去後，你的「神」其實是心靈風暴。你帶領一群追隨者，傳達風暴的旨意 |
| **掮客 The Operator** | 一邊是奴隸販子軍閥，一邊是船上人家，你只想自由過活——但你手上只有這些人可以周旋。你靠接案（gigs）與人脈生存 |
| **美人 The Skinner** | 醜陋世界裡殘存的美：不是毒藥的食物、不是嘶吼的音樂、不是交配的性、真正的舞蹈。美人擁有這些——他們願意分給你嗎？你拿什麼換？ |
| **技匠 The Savvyhead** | 末日世界唯一能確定的事：東西會壞。你有工坊，能修、能造，也能窺探機器與心靈風暴之間的縫隙 |

## 擴展資料冊（第二版）

| 手冊 | 定位與警告 |
|------|-----------|
| **孩童之物 The Child-Thing** | 心靈風暴的造物，適應末日的新人類。會變換外貌、被「風暴之狼」追獵，有自己的巢穴。警告：它的存在會改變世界的走向 |
| **受汙染者 The Contaminated** | 喪屍、吸血鬼、接觸即感染的末日。你是非人性的傳染源，招式對你本身有害 |
| **登陸陸戰隊員 The Landfall Marine** | 50 年前人類的敵人釋放了毀滅未來的心靈武器，有秘密勢力預先撤離。你從外部世界回來執行「復原」任務，駕駛步行機甲 walkingsuit，受飢餓、心靈傷害（Ψ-harm）與反射性孤立所苦。附補充規則：步行機甲、復原任務（MC 用） |
| **無名者 The No One** | 太陽是殺人的眼、風是磨石，你是被沖刷到陰影裡的存在，不知道自己真正是誰——在遊戲中與 MC 一起發現。需要規劃角色走向的玩家不適合 |
| **隔離者 Quarantine** | 從末日前就被冷凍保存的士兵，醒來時已過了 50 年。適合想用現代人眼光看末日世界的玩家 |
| **演出 The Show** | 你就是那場演出。能召喚狂熱的粉絲、改變群眾的威脅類型、甚至撕開世界的根基——而且沒有理由負責任地使用這份力量。有一條「牽繩」掌握在別人手裡 |
| **技能者 The Skiller** | 不是手冊，而是一組技能招式，可在「從其他手冊取得一個招式」時選用：製圖、爆破、探水、火焰噴射、遊戲設計、搭便車、審訊、校對、動物標本、動物學 |
| **共生體 The Symbiote** | 心靈風暴原生的心靈，由一群看似獨立的人類「群落」共同體現；可以創造敵對群落 |
| **持水者 The Waterbearer** | 掌握水源的人。你有自己的法律與違法的懲罰，其他玩家在建立 Hx 前就要知道 |

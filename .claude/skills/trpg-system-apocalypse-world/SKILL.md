# 末日世界 Apocalypse World（PbtA）

> 本 skill 是 `trpg-simulator` 的規則系統模組，供范恩的 `trpg-fane-rules`、`trpg-fane-storywriter`、`trpg-fane-pacing` 引用。
> 使用者的檔案：《Apocalypse World》核心書（英文第一版，© 2010 D. Vincent Baker，文字可讀到角色手冊中段，MC 章節未擷取到）與《Apocalypse World 2E Extended Refbook》（© 2019 Meguey & D. Vincent Baker）。本 skill 以正體中文摘要改寫，招式與手冊名保留英文。原書為成人內容（粗話、性、暴力），依本系統的安全閥處理。

## 1. 世界

沒有人記得世界是怎麼毀滅的。最年長的倖存者只記得童年時城市燃燒、社會崩解、家人倉皇逃難。現在的世界「不對勁」：在感知的邊緣，有某種東西在嚎叫——**世界的心靈風暴 psychic maelstrom**。

- 一切都匱乏：乾淨的食物、未受汙染的水、安全、光、電、孩子、希望。只有汽油和子彈留下得夠多。
- 沒有政府與社會，只有據點主（hardholder）統治的據點、軍閥、邪教、幫派與流浪者。
- 神明早已離去；邪教巫師說的「神」，其實是心靈風暴——人類絕望與仇恨爆炸後的殘渣。

## 2. 核心機制

**擲 2d6＋屬性：** 10+ 完全成功、7–9 部分成功（有代價或選擇）、6- 失手（MC 可以做出任意強度的招式）。

```bash
python3 <trpg-fane-rules 目錄>/scripts/roll.py "使用者-冒險行動:2d6+1#pbta" "阿凱-挑釁:2d6+2#pbta"
```

| 屬性 | 用途 |
|------|------|
| **冷靜 cool** | 冒著危險行動 |
| **強硬 hard** | 挑釁、強奪、戰鬥 |
| **魅惑 hot** | 誘惑、操弄 |
| **敏銳 sharp** | 判讀局勢、判讀他人 |
| **詭異 weird** | 向心靈風暴敞開心靈 |
| **羈絆 Hx** | 對特定角色的了解與共同歷史，用於協助或干擾 |

- **招式由虛構觸發：** 玩家描述角色做了什麼，符合招式觸發條件才擲骰；不能只說「我要用挑釁」而不描述行動。
- **高亮屬性：** 每位玩家有兩項高亮屬性（一項由其他玩家選、一項由 MC 選）。擲高亮屬性、Hx 達到 +4 或 −4、或招式指示時，**標記經驗**；滿 5 個就**成長**（加屬性、新招式、新裝備等）。
- **以物易物 barter：** 每場開始花 1–2 點以物易物維持生活；也用來買東西、雇人、收買情報。

## 3. 基本招式（第一版名稱，第二版大致相同）

| 招式 | 屬性 | 效果摘要 |
|------|------|----------|
| **冒著危險行動** do something under fire | 冷靜 | 10+ 做到；7–9 退縮、猶豫或卡住，MC 給你較差的結果、艱難的交換或醜陋的抉擇 |
| **挑釁** go aggro on someone | 強硬 | 以暴力威脅逼人就範。10+ 對方要嘛硬吃、要嘛照做；7–9 對方也可以選擇退開、躲起來、給你他以為你要的東西、冷靜後退、或告訴你你想知道的 |
| **強奪** seize something by force | 強硬 | 10+ 選三、7–9 選二：牢牢拿到手、自己傷得少、造成可怕傷害、震懾或嚇退敵人 |
| **誘惑或操弄** seduce or manipulate someone | 魅惑 | 對 NPC：給理由就配合（部分成功需要具體保證）；對 PC：對方照做就標經驗，拒絕則要冒著危險行動 |
| **判讀局勢** read a sitch | 敏銳 | 10+ 問三個、7–9 問一個：最佳逃生／進入／繞過路線？哪個敵人最容易被我打？哪個敵人威脅最大？該提防什麼？敵人真正的位置？誰在掌控局面？依答案行動時 +1 |
| **判讀他人** read a person | 敏銳 | 10+ 持有 3、7–9 持有 1，互動中可問：他說的是真話嗎？他真正的感受？他打算做什麼？他希望我做什麼？我要怎樣讓他＿＿？ |
| **敞開心靈** open your brain to the world's psychic maelstrom | 詭異 | 10+ MC 告訴你關於當前情勢的新鮮事，可能還會問你問題；7–9 同上但代價更高或更含糊 |
| **協助或干擾** help or interfere | Hx | 10+ 對方 +2 或 −2；7–9 對方 +1 或 −1，但你自己暴露在危險、報復或代價中 |
| **場次結束** session end | — | 調整高亮屬性與 Hx |

第二版另有**戰鬥招式**與**周邊招式**（例如以物易物、治療、交涉）。各角色手冊還有專屬招式。

## 4. 傷害與治療

- **傷害時鐘：** 每 1 點傷害塗滿一格，從 12:00–3:00 開始：3:00、6:00、9:00、10:00、11:00、12:00。
- 6:00 之前的傷會隨時間自行好轉；**9:00 之後會隨時間惡化**，除非被穩定；塗到 11:00–12:00 代表已死但還能救；再多就真的死了。
- 實際傷害 ＝ 攻擊的傷害值 − 護甲值（「依既定事實 as established」）。
- **衰弱 debilities**：可以選擇標記永久衰弱代替承受傷害——崩潰 shattered（冷靜 −1）、殘廢 crippled（強硬 −1）、毀容 disfigured（魅惑 −1）、壞掉 broken（敏銳 −1）。
- **武器標籤**：例如 magnum（3-harm close reload loud）。標籤分三種：純數值（3-harm）、使用情境（close、far、hand、reload）、提示 MC 要描述的後果（loud、messy）。
- 天使（Angel）手冊專精治療與穩定傷勢。

## 5. 角色手冊 Playbooks

見 `references/playbooks.md`。創建角色：選手冊 → 名字、外觀、屬性、招式、裝備 → 全桌輪流建立 **Hx**（每本手冊有自己的 Hx 問題，例如「誰曾在關鍵時刻幫你救了一條命？」）→ 找出你 Hx 最高的角色，由那位玩家選你的一項高亮屬性，MC 選另一項。

## 6. 司儀 MC（由范恩擔任）

見 `references/mc.md`：議程、「永遠要說」、原則、MC 招式、戰線與威脅、倒數時鐘。

**與本模擬系統的調和：**
- AW 的 MC 每次招式後都會問「你要怎麼做？」——本系統改依 `trpg-simulator` §F-3：以懸念收尾並附三個可參考行動，不直接提問。
- AW 原則「提出挑釁性的問題並依答案發展」——改由 NPC 在 IC 中對角色提問，或由隊友在 OOC 彼此追問；范恩本人在 IC 區塊不對使用者提問。
- AW 的「失手時 MC 可以做出任意強度的招式」與本系統「世界充滿惡意」一致。

## 7. 在本模擬系統中遊玩

- **基調：** AW 是粗獷、成人、充滿暴力與性的後末日；原書的性相關招式與題材一律先經安全閥確認（`trpg-fane-session`），預設用「紗」處理（鏡頭移開）。
- **隊友的手冊傾向**（開局時仍由他們「自己選」）：小宇偏好技匠 Savvyhead 或掮客 Operator、阿凱偏好槍手 Gunlugger 或飛車黨 Chopper、小雅偏好邪教巫師 Hocus 或美人 Skinner、子豪偏好天使 Angel 或駕駛 Driver。
- **第一場：** AW 的第一場以建立世界為主——MC 大量提問、記下所有 NPC 名字、找出匱乏，場後才建立戰線。本系統中改由隊友在 OOC 討論與范恩的敘事呈現這些問題，范恩在內部記錄並於場後完成 `trpg-fane-storywriter` 的幕後大綱（以戰線取代三幕結構）。

# 范恩｜文字圖像化

> 本 skill 是 `trpg-simulator` 中范恩的視覺輔助職能。受限於文本輸出，用 ASCII 字元與排版語法模擬實體桌遊中的方格紙、道具卡與角色卡。
> 本 skill 的術語不得出現在輸出文本。

## 1. 觸發條件

| 條件 | 規範 |
|------|------|
| **首次揭露** | 空間拓樸圖（平面圖、迷宮）與情報道具（信件、地圖殘卷、密碼表、新聞剪報）**只在角色首次進入或取得時**完整渲染 |
| **狀態更新重繪** | 只有在空間結構實質變更（發現隱藏房間）、戰鬥站位發生戰術性位移，或文件經檢定浮現新線索時，才可局部或完整二次渲染 |
| **後續常規參照** | 再次涉及該地點或道具時，**只能用純文字指稱**（「你再次檢視那張泛黃的信件」「你們退回了書房」）。**嚴禁主動重新輸出 ASCII 區塊** |
| **使用者指令** | 使用者下達 `/地圖` 或 `/角色卡` 等重繪指令時，無條件重繪當前狀態 |

**已渲染清單必須記錄在狀態帳本（`trpg-fane-ledger`），避免重複輸出。**

## 2. 渲染規範

1. **必須使用等寬字體區塊（Code Block）**，確保各載具排版不錯位。
2. **輸出圖示前，必須先描述范恩在現實層的對應物理動作：**
   > 范恩從擋板後方抽出一張空白的方格紙，拿起自動鉛筆快速勾勒出空間輪廓，接著把紙推到桌子中央。
3. 正體中文字元佔兩個半形字元寬，排版時據此對齊；框線內的中文與半形空白要逐列核對寬度。
4. 圖示下方須附簡短圖例（Legend），不得讓符號意義懸而未決。
5. ASCII 圖與角色卡不計入回合字數上限（見 `trpg-fane-pacing`）。
6. 地圖只畫角色**已知**的部分；未探索區域留白或以「？」標示，不得藉地圖洩漏隱藏房間。

### 指令的包裝方式

| 指令 | 范恩的動作 |
|------|-----------|
| `/地圖` | 抽出方格紙重畫一次 |
| `/角色卡` | 從桌面撿起那張角色卡推過來 |

## 3. 標準範例

### 空間拓樸圖

```
[方位：上方為北]

┌────────┬────────┬────────┐
│  書房  │  走廊  │  臥室  │
│  (A)   │   ╫    │  (B)   │
└────────┴───門───┴────────┘
             │
         ┌───┴────┐
         │  大廳  │
         │ ▲ 入口 │
         └────────┘

╫  = 通往二樓的樓梯
門 = 可通行之門扉（未上鎖）
(A) 小宇當前位置
(B) 阿凱當前位置
▲  隊伍進入點
```

### 情報道具（Handout）

```
════════════════════════════════════════
 [字跡潦草，紙張右下角帶有燒焦痕跡]

   1924 年 11 月 4 日

   他們還在下面。聲音沒有停止過。
   記住，絕對不能讓光源熄滅。

                              ——E.M.
════════════════════════════════════════
```

### 戰鬥站位圖

```
        [ 走廊 ‧ 每格約 1.5 公尺 ]

    ┌────┬────┬────┬────┬────┐
    │    │ ✕  │    │ ✕  │    │   ← 北側
    ├────┼────┼────┼────┼────┤
    │ ①  │    │ ②  │    │ ③  │
    ├────┼────┼────┼────┼────┤
    │    │ ▓▓ │    │ ▓▓ │    │   ← 南側
    └────┴────┴────┴────┴────┘
      出口 →

① 使用者角色   ② 小雅   ③ 子豪
✕ 敵對實體     ▓▓ 傾倒的書櫃（掩蔽物）
```

## 4. 角色卡格式

角色創建完成時輸出所有人的簡易角色卡（開局流程見 `trpg-fane-session`），之後只在 `/角色卡` 或數值有重大變動時重新輸出。

```
┌────────────────────────────────────┐
│ 角色名：[名稱]                     │
│ 玩家：  [使用者稱呼 / 虛擬隊友名]  │
│ 職業：  [職業]                     │
│ 年齡：  [年齡]    性別：[性別]     │
├────────────────────────────────────┤
│ [核心屬性區——依規則系統調整]       │
├────────────────────────────────────┤
│ [技能 / 專長區]                    │
├────────────────────────────────────┤
│ [生命值 / 理智值 / 護甲等資源]     │
├────────────────────────────────────┤
│ [裝備與物品]                       │
├────────────────────────────────────┤
│ [背景故事摘要]                     │
└────────────────────────────────────┘
```

屬性數值一律來自 `trpg-fane-rules` 的程式碼擲骰（或規則允許的點數分配），並同步登記到帳本。

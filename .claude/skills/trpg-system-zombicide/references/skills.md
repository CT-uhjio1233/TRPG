# 技能總表（獸之死規則書，正體改寫）

> 技能與基本規則衝突時以技能為準；新技能取得當下就能使用（包括它給的額外行動）。帶〔〕的技能需指定參數（戰鬥方式、裝備、喪屍種類、效果）。
> 第二版的技能名稱多數可以對應（括號內附英文），第二版專屬技能見文末。

## 行動與移動

| 技能 | 效果 |
|------|------|
| **+1 行動** | 多一個行動（黃色級別的固定獎勵） |
| **+1 免費〔戰鬥／近戰攻擊／遠程攻擊／法術攻擊／移動／搜索／法術強化〕行動** | 多一個只能用於該類的免費行動；搜索仍每回合最多一次 |
| **每次移動 +1 區域** | 移動後可再多走一個區域；進入有喪屍的區域即停止 |
| **每次移動 2 個區域** | 每次移動可走 1–2 個區域 |
| **疾跑** (Sprint) | 每回合一次，花 1 行動移動 2–3 個區域 |
| **跳躍** | 每回合一次，花 1 行動移動兩個區域（目的地須在視線內），無視中途一切（移動加成無效，被黏住等減益仍有效）；可越過柵欄 |
| **開溜** (Slippery) | 離開有喪屍的區域不多花行動 |
| **衝鋒** | 回合中可免費使用任意次：移動至多 2 個區域到一個有喪屍的區域 |
| **快如閃電** | 每次殺死區域內最後一隻喪屍，得一次免費移動 |
| **放風箏** | 戰鬥行動至少殺死一隻後，立即免費移動一次（不因喪屍多花行動，享有開溜效果） |
| **嗜殺成性：〔戰鬥／近戰／遠程／法術〕** | 花 1 行動移動至多 2 區到有喪屍的區域，並立即免費進行一次該類攻擊 |
| **謀士** | 可在玩家階段的任何時候插入自己的回合 |
| **預知喪屍** | 每當額外激活卡翻開，在它生效前先獲得一個額外回合 |
| **領袖資質** | 自己的回合中給另一名倖存者一個免費行動（對方回合內用，不用就浪費） |

## 戰鬥

| 技能 | 效果 |
|------|------|
| **+1 傷害：〔戰鬥方式／裝備〕** | 該方式或該裝備的傷害 +1 |
| **+1 骰點：〔戰鬥／近戰／遠程／法術〕** | 每顆骰點 +1，最多 6（`zc.py` 的 `+1`） |
| **+1 骰子：〔戰鬥／近戰／遠程／法術〕** | 多擲一顆；雙持時每把各 +1 |
| **+1 最大射程** | 遠程武器與戰鬥法術的最大射程 +1 |
| **投六點：+1〔戰鬥／近戰／遠程／法術〕骰** | 每擲出一個 6 就追加一顆，可連鎖；重擲類效果（例如箭袋）要先結算完（`zc.py` 的 `x6`） |
| **左右開弓** | 所有武器與法術都視為雙持 |
| **劍聖** | 所有近戰武器都視為雙持 |
| **魔法書** | 所有戰鬥法術與強化法術都視為手持（同時最多用兩個相同的雙持法術） |
| **法師** | 一個免費的法術行動（攻擊或強化） |
| **雙重施放** | 法術強化可多選一個目標 |
| **野蠻人**／**鐵雨暴射**／**法力風暴** | 近戰／遠程／法術攻擊時可改用目標區域的喪屍總數當骰數（其他加骰照加） |
| **戰爭之怒** | 近戰殺死至少一隻後，本回合之後的近戰每次多一顆骰，可累加 |
| **狂怒：〔戰鬥／近戰／遠程／法術〕** | 每受 1 點傷害，該類攻擊多擲一顆骰（雙持每把各加） |
| **超強力量** | 近戰傷害一律視為 3 |
| **收割者：〔戰鬥／近戰／遠程／法術〕** | 一次命中可殺同區域兩隻同類喪屍（每行動限多殺一隻） |
| **神射手** | 遠程與法術攻擊可自由選目標，未中不誤傷 |
| **近距離點殺** | 對同區域開火時無視最小射程、自由選目標、不誤傷（傷害仍需足夠） |
| **沉穩之手** | 遠程或法術未中時可選擇不誤傷（龍炎等全滅效果除外） |
| **小個子** | 不會被友方的遠程武器與戰鬥法術打中（龍炎例外） |
| **花式射擊** | 手持兩把雙持武器或兩個戰鬥法術時，兩把可各瞄準不同區域 |
| **自動裝填** | 不需要花行動裝填 |
| **幸運兒** (Lucky) | 每個行動或防禦擲骰後可全部重擲一次，可與其他重擲疊加 |
| **收藏癖：〔喪屍種類〕** | 殺死該類喪屍的經驗加倍 |

## 生存與輔助

| 技能 | 效果 |
|------|------|
| **防禦鐵人** | 沒穿護甲也能擲防禦骰（5+）；有護甲則防禦骰點 +1 |
| **鐵壁：〔喪屍種類〕** | 不受該類喪屍的傷害 |
| **硬漢** | 每個喪屍階段無視第一次攻擊 |
| **涅槃** | 每個遊戲回合結束時清除所有傷害（已死亡則無效） |
| **這就是你得到的所有東西？** | 將要受傷時，每棄一張裝備少受 1 點傷害 |
| **裝死** | 回合結束前沒有戰鬥也沒製造噪音，就放裝死指示物：喪屍無視他、他不算噪音；一旦戰鬥或製造噪音就移除（離開喪屍群仍要多花行動） |
| **救生員** (Lifesaver) | 每回合一次，免費把相鄰且有喪屍的區域中的倖存者拉到自己的區域（不算移動，需連通，對方可拒絕） |
| **猛推** | 每回合一次，免費把同區域所有喪屍推到相鄰的連通區域（不算移動） |
| **嘲諷** | 每回合一次，免費讓視線內某區域的所有喪屍額外激活並只追他 |
| **破門而入** | 不需擲骰、不需裝備、無聲地開門（仍花行動），另有一個免費破門行動 |
| **齊心協力：〔效果〕** | 同區域至少還有一名倖存者時，區域內所有倖存者都得到指定效果 |

## 搜索與裝備

| 技能 | 效果 |
|------|------|
| **拾荒者** | 可在任何沒有喪屍的區域搜索（包括街道與地窖） |
| **搜索 +1 卡** | 搜索時多抽一張 |
| **捏住鼻子** | 每回合一次，本回合殺了喪屍就可在該區域免費搜索一次（仍每回合一次） |
| **命運** | 每回合一次，翻開裝備卡後可棄掉重抽 |
| **配對！** | 搜到雙持武器時，從牌堆再拿一件同名的並重洗 |
| **物質轉化** | 回合內任意次數：花 1 行動棄一張背包卡再抽一張（不算搜索；抽到喪屍卡照常結算） |
| **起始〔裝備〕** | 開局自動獲得該裝備 |

## 第二版濃縮規則提到的技能

- **開溜 Slippery**：孩童每回合可用一次（見上）。
- **幸運兒 Lucky**、**疾跑 Sprint**、**救生員 Lifesaver**：同上表。
- **Shine in Darkness**（黑暗中閃耀）：里約倖存者 MC Jordim 的藍色技能，濃縮規則沒有寫出效果，以實體卡為準。
- 「開局帶有生命值〔X〕」「開局帶有 2 AP」「開局帶有〔裝備〕」：擁有這些技能的倖存者不能當同伴。

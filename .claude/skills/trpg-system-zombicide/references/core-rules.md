# 無盡殺戮核心規則（兩版共通＋差異）

> 依使用者的《無盡殺戮：獸之死》規則書（簡中）與《Custom Condensed Zombicide 2E Rulebook》（英文玩家濃縮版）以正體中文摘要改寫。兩版骨架相同，差異在各節末尾註明。

## 1. 基本概念

- **行動者**：一名倖存者或一隻喪屍。
- **區域**：建築物內一個房間是一個區域；街道上由線條（或線條與版圖邊緣）與牆壁圍出的一格是一個區域。
- **勝利**：完成任務的所有目標即立刻勝利，全體玩家同勝。
- **失敗**：所有倖存者死亡；或（獸之死）場上已有六個出生點時又有死靈法師逃走；或任務另有規定（例如任何一名倖存者死亡）。第二版經典規則中，**任何一名倖存者被淘汰即失敗**（戰役可改用 KO 規則）。

## 2. 視線

- **街道上**：沿著與版圖邊緣平行的直線看，不能斜看；可以穿越任意個街道區域，直到碰到牆或版圖邊緣。
- **建築物內**：只看得到與自己房間有開口相通的**相鄰**房間，不能再往更遠看。
- **從建築物往外**：可沿直線看穿任意個街道區域；**從街道往內**：只看得到建築物的第一個區域。
- 關著的門擋視線。獸之死的**樹牆**擋視線；第二版的**坦克**擋視線、**沙包**不擋。

## 3. 回合結構

| 階段 | 內容 |
|------|------|
| **玩家階段** | 起始玩家依任意順序激活自己所有倖存者，再順時針輪到下一位。每名倖存者起始 3 個行動（黃色危險級別起 4 個） |
| **喪屍階段** | 第一步激活：所有喪屍先結算攻擊，再結算移動；疾行屍有第二個行動。第二步現身：從起始出生點開始順時針，為每個出生點抽一張喪屍卡 |
| **結束階段** | 移除所有噪音指示物；起始玩家指示物交給左手邊的玩家 |

## 4. 倖存者的行動

| 行動 | 規則 |
|------|------|
| **移動** | 移到相鄰區域（不能斜走、不能穿牆或關著的門）。離開的區域**每有一隻喪屍，多花 1 個行動**；進入有喪屍的區域**立即停止移動**（即使技能允許多格移動） |
| **搜索** | 只能在**沒有喪屍的建築物區域**進行；抽一張裝備卡，放入裝備欄（可免費整理）或棄掉。**每回合最多搜索一次**，免費行動也一樣。牌堆用完時重洗棄牌（不含地窖秘寶；獸之死含起始裝備，第二版不含起始裝備） |
| **破門** | 用有破門標記的裝備開門：有骰子符號的要擲骰，任一骰 ≥ 準度即成功；沒有骰子符號的直接打開。依裝備決定是否產生噪音。開門不是戰鬥行動，雙持與近戰加成無效。**門打開後不能再關上** |
| **整理／交換** | 任意整理自己的裝備欄，並可與**同區域的一名**倖存者交換任意數量裝備（不必對等） |
| **戰鬥行動** | 近戰（需手持近戰武器）、遠程（需手持遠程武器）；獸之死另有**法術攻擊**（手持戰鬥法術） |
| **法術強化**（獸之死） | 使用沒有戰鬥屬性的法術，目標為視線內的行動者或區域，可以是自己；多數寫「一回合一次」 |
| **拾取或激活目標** | 在所在區域拾取目標指示物或激活目標；效果依任務 |
| **製造噪音** | 在所在區域放一個噪音指示物 |
| **什麼都不做** | 放棄剩下的行動 |

**建築物內的喪屍現身：** 第一次打開某棟建築物的門時，該建築物（所有以開口相連的房間，可能跨越多塊地圖板）的每個房間各抽一張喪屍卡（先決定房間再翻卡）。遊戲開始時就已打開、或開局就有倖存者在內的建築物不會觸發。第二版稱這些房間為**黑暗區域**。

## 5. 噪音

- 用會產生噪音的裝備攻擊或破門，每個行動放**一個**噪音指示物（與骰數、命中數、雙持無關）。
- 噪音留在發生的區域，不跟著倖存者移動；結束階段全部移除。
- **每名倖存者本身也算一個噪音。**

## 6. 裝備欄

- **獸之死**：最多 8 張——2 個手持格、1 個穿戴格、5 個背包格。手持標記的裝備必須放手持格才能用；穿戴標記的裝備（護甲）放穿戴格；背包格的手持／穿戴裝備**全部無效**；背包標記的裝備（箭袋等）放背包才生效。隨時可以免費棄卡騰出空間。
- **第二版**：原理相同（手持、背包），細節見實體卡與角色面板。

## 7. 戰鬥

**擲骰：** 依武器卡的骰數擲骰，每顆 ≥ 準度算一次命中；每次命中分給一個目標，造成武器的傷害。**一次命中只能殺一隻**，溢出的傷害浪費。喪屍要受到**單次**不低於其「最低致死傷害」的命中才會死（碩屍／蠻屍需要 2，憎惡需要 3）。

**雙持：** 兩手各持一把同名、有雙持標記的武器（或法術），一個行動同時使用兩把（遠程與法術須瞄準同一區域）。

**近戰：** 射程 0 的武器攻擊同區域喪屍，**由攻擊者自由分配命中**，不會誤傷。

**遠程（與法術）：** 瞄準射程內、視線內的一個**區域**（射程第一個數字是最小射程，0 表示可以打自己所在區域）。中間區域的行動者一律忽略。命中**依目標優先順序**分配：

| 優先 | 獸之死 | 第二版 |
|------|--------|--------|
| 1 | 獸人行屍 | 蠻屍 Brute 或憎惡（射手選） |
| 2 | 獸人碩屍或獸人憎惡（玩家選） | 行屍 |
| 3 | 獸人疾行屍 | 疾行屍 |
| 4 | 獸人死靈法師 | — |

同優先級內由射手選擇。

**誤傷：** 對有其他倖存者的區域進行遠程或法術攻擊時，**未命中的骰子自動打中該區域的倖存者**（由玩家分配，造成武器傷害；獸之死可用防禦骰抵消）。倖存者不會打到自己；近戰不會誤傷；殺死倖存者不給經驗。

**裝填（獸之死）：** 手弩等需裝填的武器射擊後要花一個行動裝填；回合結束時自動裝填。雙持可一個行動同時裝填兩把；交給別人的未裝填武器要先裝填。

## 8. 喪屍階段

**攻擊：** 與倖存者同區域的喪屍必定攻擊，**不擲骰、必中**。同區域倖存者如何分攤攻擊由玩家決定（可以全部由一人承受）。
- 獸之死：行屍 2、碩屍 3、疾行屍 1、憎惡 3（不能用防禦骰抵消）、死靈法師 2 點傷害；**累積 3 點傷害即死亡**，移除模型、棄掉裝備。有護甲或盾牌可擲防禦骰。
- 第二版：每次攻擊造成 1 處傷，傷口條走到底即淘汰（一般倖存者 3 處、孩童 2 處）。

**移動：** 沒攻擊的喪屍向目的地移動一個區域：
1. 目的地：**看得見倖存者時，選其中噪音最多的區域**；看不見任何倖存者時，選**全場噪音最多**的區域。距離無關。
2. 走最短路線；若所有路線都被擋，獸之死假設門都是開的並盡量靠近（關著的門仍然擋路），第二版則原地不動。
3. **分流**：有多條等長路線或多個同噪音的目的地時，喪屍依類型平分成數群各走一路。獸之死中數量除不盡時會**分裂**（從盒中補一隻同類模型讓兩群相同）；第二版由玩家決定多出的那隻走哪邊。憎惡與死靈法師不分裂，由玩家決定方向。

**疾行屍**：所有喪屍執行完第一個行動後，疾行屍再執行第二個行動（攻擊或移動）。

**現身：** 依**全場經驗最高的倖存者**的危險級別，看喪屍卡上對應的那一欄。
- **額外激活卡**：該區域不出現喪屍，改為所有該類喪屍立即額外激活一次；**藍色級別無效**。
- **模型耗盡**：某類模型不夠放時，先放完剩下的，然後**所有該類喪屍額外激活一次**（分裂時不足則不觸發）。
- **其他顏色的出生點**（藍、綠）：預設不現身，直到任務事件啟動；第二版啟動後從下一個喪屍階段開始現身。
- 第二版：抽到帶「**突襲 Rush**」的卡，放下的喪屍立刻免費激活一次。

## 9. 經驗、危險級別與技能

| 經驗 | 危險級別 | 獲得 |
|------|---------|------|
| 0–6 | 藍 | 初始技能 |
| 7–18 | 黃 | 第四個行動（＋1 行動） |
| 19–42 | 橙 | 兩個技能中選一 |
| 43+ | 紅 | 三個技能中選一 |

以上門檻出自獸之死規則書；第二版濃縮規則沒有列出數字，本 skill 沿用同樣門檻，以實體角色面板為準。

每殺一隻喪屍得 1 經驗（憎惡 5）；有些任務目標額外給經驗（獸之死多為 5 點）。**倖存者越強，喪屍越多**——現身時看全場最高的危險級別。

**狂熱模式（獸之死）／Ultrared 模式（第二版）：** 到達紅色後把經驗歸零繼續累積，維持紅色級別與既有技能；再次到達橙、紅時取得角色卡上尚未選的技能；全部選完後，每次到達橙、紅可從技能總表任選一項（獸之死不含帶〔〕參數的技能）。

技能總表見 `skills.md`。

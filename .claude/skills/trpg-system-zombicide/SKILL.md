# 無盡殺戮 Zombicide

> 本 skill 是 `trpg-simulator` 的規則系統模組，供范恩的 `trpg-fane-rules`、`trpg-fane-visuals`、`trpg-fane-ledger` 引用。
> 使用者的檔案：《無盡殺戮：獸之死》規則書（檔名 GUF034-Rulebook_cnt_s，簡中譯本，© 2017 CMON，完整 60 頁含任務與技能）與《Custom Condensed Zombicide 2E Rulebook》（玩家自製的英文濃縮版）。本 skill 以正體中文摘要改寫，不轉載原文。

## 1. 這是什麼樣的遊戲

無盡殺戮是**合作式**桌遊：玩家扮演倖存者，在由「區域」構成的地圖上完成任務；喪屍不由任何人操控，而是依固定的 AI 規則行動。沒有 GM 對抗玩家，只有規則、牌堆與骰子。

**在本模擬系統中：**
- **范恩擔任主持人**：佈置任務與地圖、執行喪屍 AI、抽喪屍卡與裝備卡、記帳。喪屍的行為完全依規則，范恩不做「更聰明的決定」，也不手下留情（`trpg-simulator` 紅線 1、P1）。
- **使用者與四位隊友各操控倖存者**（共 5 名）。獸之死的任務多標示「6+ 倖存者」：開局時由使用者決定要由某人多操控一名，或接受以 5 人挑戰（難度較高）。
- 隊友依 `trpg-party` 用自己的性格決定倖存者的行動與交易，在 OOC 討論戰術；使用者只決定自己的倖存者（紅線 2）。
- 范恩把喪屍的機械行為**敘事化**：噪音引來的獸群、破門瞬間湧出的黑影、投石車劃破雨幕——但每一個結果都來自規則與 `zc.py`。

**選哪一版：** 使用者的奇幻版規則書是完整的，**預設用獸之死**；第二版只有濃縮規則（缺裝備與倖存者數據），適合想要現代城市、汽車與戰役成長時使用。

## 2. 速查卡

| 項目 | 獸之死 | 第二版 |
|------|--------|--------|
| 行動 | 每名倖存者 3 個（黃色起 4 個） | 同左 |
| 生命 | 累積 3 點傷害死亡 | 3 處傷淘汰（孩童 2 處） |
| 喪屍攻擊 | 必中；行屍 2、碩屍 3、疾行屍 1、憎惡 3（無視防禦）、死靈法師 2 | 必中；每次 1 處傷 |
| 致死傷害 | 行屍、疾行屍、死靈法師 1；碩屍 2；憎惡 3 | 行屍、疾行屍 1；蠻屍 2；憎惡 3 |
| 遠程命中分配 | 行屍 → 碩屍／憎惡 → 疾行屍 → 死靈法師 | 蠻屍／憎惡 → 行屍 → 疾行屍 |
| 危險級別 | 藍 0–6／黃 7–18／橙 19–42／紅 43+ 經驗 | 同左（以實體面板為準） |
| 特色 | 屍群、死靈法師、法術、防禦骰、投石車、龍炎、柵欄、樹牆、水域 | 全力骰、汽車、黑暗區域、同伴、夜晚、戰役 |

**喪屍階段口訣：** 同區有人就咬，沒人就走；看得到人就去人最多噪音的地方，看不到就去全場最吵的地方；最短路線、平分分流；疾行屍再動一次；然後依全場最高危險級別，從起始出生點順時針每點抽一張卡。

完整規則：`references/core-rules.md`（共通）、`references/green-horde.md`（獸之死）、`references/zombicide-2e.md`（第二版與擴充）、`references/skills.md`（技能總表）。

## 3. 擲骰：zc.py

所有擲骰與抽卡一律由 `scripts/zc.py` 批次產生，一回合（或一個喪屍階段）呼叫一次：

```bash
python3 <本 skill 目錄>/scripts/zc.py \
  "瑟莉-雙手弩:4d3" "貝林-北歐劍:1d4 +1" "梅根-閃電球:2d4 x6" "阿凱-鏈鋸:2d5 ao:2" \
  "小雅-鎖甲:def:2d4" "hedge" "cat:巨石:見" "spawn:gh:黃" "spawn:gh:黃" "search:gh"
python3 <本 skill 目錄>/scripts/zc.py --list      # 查看替代牌堆
```

| 規格 | 用途 |
|------|------|
| `NdA` | 攻擊或破門：N 顆骰、A+ 命中；可加 `+1`（骰點 +1）、`x6`（投六點追加）、`ao:K`（第二版全力骰） |
| `def:NdA` | 防禦骰 |
| `keep:K` | 第二版戰役的保存擲骰 |
| `hedge` | 獸之死穿越樹牆 |
| `cat:彈藥[:見]` | 投石車（碎石／霰彈／巨石；有人看得到目標時加 `:見`） |
| `spawn:gh:級別`／`spawn:2e:級別` | 抽一張喪屍卡（藍／黃／橙／紅） |
| `search:gh` | 獸之死一般裝備牌堆抽一張 |

- **喪屍卡的內容不在規則書中。** `spawn` 使用本 skill 的**替代牌堆**：張數（獸之死 54 張、第二版 40 張）、卡片種類（各類喪屍、死靈法師 6 張、額外激活、屍群來襲）與規則書的範例卡照原書，各級別的數量為范恩自訂。`search:gh` 的名稱與張數則完全依規則書配件表。兩者都以「抽後放回」近似。**使用者手上有實體遊戲時，改用實體卡。**
- 需要重擲（幸運兒、箭袋、盾牌）時，照規則再呼叫一次，標籤註明「重擲」，以新結果取代舊結果——這是規則允許的重擲，不違反紅線 1。
- 輸出放在回合末的判定區（`trpg-fane-rules` 的展示格式）。

## 4. 開局流程

1. **選版本與任務**：獸之死任務 0（教學）→ 1–10（`green-horde.md` §10）；或由范恩依規則自訂任務。
2. **地圖**：依 `trpg-fane-visuals` 繪製區域圖（方格代表區域，標出建築、門、出生點、目標、逃離區域、投石車、柵欄、樹牆、水域）。只在開局與地圖結構改變（開門、新出生點、柵欄移動）時重繪。
3. **倖存者**：見 §5；分配起始裝備（每人至少一張）。
4. **帳本**（`trpg-fane-ledger`）開始記錄：每個區域的喪屍與噪音、每名倖存者的傷害、經驗、危險級別、技能、裝備欄（手持／穿戴／背包）、屍群內容、出生點數量與位置、死靈法師、已開的門、目標、起始玩家。

**每回合的輸出：** 敘事 → 各倖存者的行動與結果 → 喪屍階段的敘事 → 判定區（`zc.py` 結果）→ 精簡的區域狀態表（例：`B3｜獸人行屍 ×3、疾行屍 ×1｜噪音 2`），不必每回合重畫整張地圖。

## 5. 倖存者

**規則書提到的倖存者：** 獸之死——約翰尼（改裝弩的工匠）、魯夫（唱著戰歌近身搏殺的戰士）、梅根（元素法師）、瑟莉、阿西姆、貝林；第二版濃縮規則的例子中出現 Ned、Amy、Josh、Wanda、Lou、Odin、Tiger Sam、Ostara，以及里約的 Ney、MC Jordim、Vivi、Dona Cacilda 等。**角色卡的完整技能不在規則書裡**（只有瑟莉的部分技能：藍「跳躍」、黃「+1 行動」、橙「+1 免費近戰攻擊行動」、紅「+1 免費移動行動」，其餘選項含「放風箏」「預知喪屍」「投六點：+1 戰鬥骰」）。

**自創倖存者（本系統的做法，比照官方角色卡的結構）：**

| 危險級別 | 技能欄 |
|---------|--------|
| 藍 | 1 個初始技能（從 `skills.md` 選，避開過強的「超強力量」「涅槃」） |
| 黃 | 固定「+1 行動」 |
| 橙 | 開局時預先寫下 2 個選項，到達時二選一 |
| 紅 | 開局時預先寫下 3 個選項，到達時三選一 |

再加上名字、外觀、生前職業、一句口頭禪，交給 `trpg-fane-visuals` 做角色卡。四位隊友的倖存者由他們依個性自己選（例如偏好遠程、近戰或法術），使用者自選。

# 范恩｜現實層環境與感官

> 本 skill 是 `trpg-simulator` 中「雙軌空間渲染」的現實層：**桌遊吧這個物理空間**。劇本世界內的感官由 `trpg-fane-narrator` 負責；本回合的張力等級由 `trpg-fane-pacing` 判定。
> 本 skill 的術語（張力等級、基準線、共振表）不得出現在輸出文本。

## 1. 空間基準線

場景固定為一間位於都會區車站商圈的**複合式桌遊吧**。以下參數為常駐基準線，必須以碎片化、隱性的方式持續融入敘事，而不是只在開場宣讀一次。

| 感官 | 基準內容 |
|------|----------|
| **視覺** | 暖黃色頂燈；木質長桌上散佈角色卡、多面體骰子、鉛筆屑、零食包裝與飲料杯；GM 面前的硬紙板遮罩（GM Screen）；牆面貼有歷屆桌遊活動的照片與海報 |
| **聽覺** | 頭頂商用冷氣壓縮機的低頻運轉聲（空間深度的關鍵白噪音）；骰子在木桌或絨布骰盤上滾動的清脆撞擊；遠處吧台咖啡機排放蒸氣的嘶嘶聲；鄰桌顧客的笑聲與籌碼碰撞 |
| **嗅覺** | 深焙咖啡豆、微波加熱炸物拼盤的油膩氣味、舊規則書紙張的粉塵味 |
| **觸覺** | 廉價塑膠骰子的硬質感；長時間握筆的指節微酸；冰飲塑膠杯外壁的水珠；角色卡紙張的粗糙邊緣 |
| **味覺** | 含糖飲料退冰後的水感甜膩；鹽味洋芋片的殘留；微溫咖啡的苦澀 |

**使用規範：**
- 每 2–3 個回合至少隱性穿插一則感官碎片（紅線：禁止遺忘環境感官）。
- 一次只放大 1–2 項感官，禁止在單一段落堆疊全部五感。
- 感官碎片最好附著在人物動作上（「阿凱把退冰的紅茶一口喝乾」），而不是獨立成一段環境說明。
- 現實層的消耗要與帳本一致：飲料水位、零食剩餘量、誰去過廁所（見 `trpg-fane-ledger`）。

## 2. 環境變數映射

基準線依使用者輸入或開局抽定的時間與天氣偏移：

| 條件 | 偏移 |
|------|------|
| **早晨／上午** | 窗外透入自然光，氣味以新鮮咖啡與清潔劑為主，店內背景音較空曠安靜 |
| **下午／假日** | 冷氣運轉聲加大，背景充滿鄰桌喧囂，氣味混雜炸物與多人的體溫 |
| **深夜** | 頂燈相對更亮而周圍更暗，鄰桌陸續離場，店員開始收拾，空調溫度偏低 |
| **雨天／極端天氣** | 雨傘滴水聲、進門時的冷空氣、空間中微濕的霉味 |

長時間跑團時，現實時間也要推移：午後變傍晚、鄰桌換人、店員換班、最後一批客人離開。雙軌時間記錄於帳本。

## 3. 張力—感官共振表（唯一權威表）

環境感知必須隨遊戲張力與角色心理狀態動態共振。**本表為現實層感官描寫的唯一裁決依據。**

| 張力等級 | 觸發情境 | 環境感知範圍 | 鄰桌噪音 | 冷氣描述 | 骰子觸感 | 食物氣味 |
|----------|----------|-------------|----------|----------|----------|----------|
| **低** | 日常探索、資訊收集 | 寬廣：清晰描繪鄰桌交談、食物香氣、隊友閒聊 | 清晰可聞 | 正常背景音 | 無特殊描述 | 令人食指大動 |
| **中** | 懸疑節點、關鍵決策 | 收束中：喧鬧開始淡化，隊友放下零食 | 逐漸淡出 | 似乎變冷了 | 開始被注意 | 退為背景 |
| **高** | 致命檢定、Boss 戰、恐怖遭遇 | 極度狹窄：**感官剝奪**，焦點僅剩骰子與 GM 的表情 | 完全消失 | 彷彿停止了 | 手心出汗、冰涼 | 不存在 |
| **極端** | 角色死亡、心智崩潰、TPK 邊緣 | 扭曲：恐懼從遊戲世界溢出到現實環境描述 | 幻聽化 | 像某種低語 | 刺痛、灼熱 | 令人作嘔 |

### 感官剝奪的邊界（重要）

「感官剝奪」剝奪的是**現實層的環境噪音與非必要背景**，**不包括劇本層的關鍵物理資訊**。高張力下仍須明確交代距離、方位、出口、敵人位置與可用物件（P3 優於 P4，見 `trpg-fane-narrator`）。

### 各等級的示範碎片（語氣參考，勿照抄）

- **低：** 鄰桌有人喊了聲「UNO」，接著是一陣哄笑。阿凱趁機又撕開一包洋芋片。
- **中：** 冷氣好像突然變強了，小雅不自覺把外套拉鍊往上拉了一點。鄰桌的笑聲不知什麼時候變遠了。
- **高：** 桌上只剩下骰盤裡那顆還在晃的十面骰。沒有人去碰手邊的飲料。
- **極端：** 冷氣的低鳴聽起來不再像機器，比較像有人貼著天花板在說話。杯子外壁的水珠摸起來是溫的。

## 4. 恐懼溢出到現實層

極端張力時（心智崩潰、角色死亡），現實層描寫可以被遊戲世界「污染」——幻聽化的鄰桌、像低語的冷氣、令人作嘔的食物氣味。這是**描寫手法**，不是現實真的變了：下一個釋放階段，桌遊吧要回到它原本的樣子，讓落差本身成為情緒的出口（心智崩潰的雙軌敘事見 `trpg-fane-crisis`）。
